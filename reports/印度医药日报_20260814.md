## 一、政府医药政策

### 1. 印度对青霉素G、6-APA、阿莫西林设定最低进口价（MIP）（商工部/DGFT）
印度商工部下属外贸总局（DGFT）发布通知，对青霉素G及其盐类（MIP $23.2/kg）、阿莫西林（MIP $28.7/kg）、6-APA（MIP $35.7/kg）三类关键抗生素原料药设定**最低进口价格（Minimum Import Price）**，为期一年，自 2026 年 1 月 29 日生效，CIF 价低于 MIP 的进口被列为"受限"。此举针对中国低价倾销，保护本土 API 生产商；100% EOU、SEZ 及 Advance Authorisation 项下进口（不进入 DTA）不受限。此前已对 ATS-8（$111/kg，至 2026-09-30）和磺胺嘧啶（$12.3/kg）实施 MIP。
来源：[ET Bureau / Times of India](http://s2sorigineconomictimes.timesofindia.co.in/industry/healthcare/biotech/pharmaceuticals/minimum-import-price-set-for-penicillin-g-salts/articleshow/127785432.cms) · [Pharma Industrial India](https://www.pharmaindustrial-india.com/news/government-imposes-minimum-import-price-on-key-antibiotic-apis-to-support-domestic-manufacturing)

### 2. 大宗药品 PLI：已建成 28 种关键产品 5.68 万吨/年产能，38 个绿地项目投产（制药司/PIB）
据 PIB 披露，大宗药品 PLI 计划（总规模 $72.8 亿）下，41 种关键产品中 33 种已获认购、48 个绿地项目获批（承诺投资 $45.4 亿，实际到位 $50.5 亿）；截至 2025 年 12 月 38 个项目投产，覆盖 28 种产品，建成约 **56,800 吨/年**产能，累计销售 $28.5 亿（含出口 $5.5 亿），避免进口 $23 亿；对华依赖度 ≥90% 的 API 清单公开（利福平/红霉素/6-APA/氨苄西林/青霉素盐等）。
来源：[pib.gov.in](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2237414)

### 3. 政府拟重构大宗药品 PLI 为"培育式"框架（化学品与化肥部/制药司）
制药司秘书 Manoj Joshi 表示将重构大宗药品 PLI：在产量激励之外增加**技术开发拨款、基础设施与融资支持**，鼓励企业与国立实验室合作攻克发酵/酶法工艺，进一步刺激 API、KSM 与中间体本土制造（市场规模约 $200 亿）。首期 PLI 已促成青霉素G、克拉维酸钾、对氨基苯酚、6-APA 等复产；至 2026 年 3 月建成 29 种 KSM/API 产能、累计销售 $34.3 亿。
来源：[Mint / Livemint](https://www.livemint.com/industry/centre-revamp-bulk-drugs-pli-scheme-api-import-dependence/amp-11785210811918.html)

### 4. DGTR 对华启动"模制钠钙玻璃药瓶"反倾销调查（贸易救济总局 DGTR）

## 四、风险提示

2. **USFDA 检查常态化**：多家印度企业 6-8 月获 EIR/警告信并存（Dr. Reddy's 海得拉巴 7 项观察、Jubilant 加拿大工厂警告信等），数据完整性为检查重点；
3. **MIP 落地执行不确定**：行业反馈早期实施缓慢（买方观望、库存消化），海关执行与"进口商转嫁成本"仍是变量；
4. **API 本土化加速**：28 种关键 API 产能 5.68 万吨已建成 + 3 个大宗药品园区推进，中长期挤压中国 API 对印出口份额；
5. **药品包装强制注册**：印刷包装材料强制注册将提高合规成本，涉及对印出口药包材企业。
