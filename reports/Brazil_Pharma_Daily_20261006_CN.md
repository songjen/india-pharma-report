## 四、本期要点

1. **GLP-1 结构性拐点**：无监管渠道首次供应多数剂量（Valor 10/4）+ 数字处方量 +304.9% + DPSP 数字渠道 70% 集中度 + Hypera 新品入场 —— 四条独立线索共同指向"原研独占权失效后的渠道与价格重构"，是本期最强信号。
2. **监管端高频动作**：ANVISA 单日（10/5）发布 5 条公告，覆盖化妆品手工生产新规、患者安全技术文件、罕见病新药注册、假冒品召回、SNCR API 开放 —— 其中 SNCR API 是 10/2 受控处方数字化的落地配套，可跟踪后续电子处方渗透率。
3. **诊断可及性突破**：阿尔茨海默病血液检测获批，把原本依赖 PET/脑脊液的高成本诊断下沉至常规实验室，对体外诊断（IVD）供应链是明确利好。
4. **生物制品本土化**：Hemobrás–天坛生物免疫球蛋白扩产（10/2）与 Bio-Manguinhos mRNA 疫苗/先进疗法并行推进，中国供应商在血制品与 mRNA 上游的机会窗口值得单独评估。
