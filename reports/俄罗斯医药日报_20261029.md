## 一、政府医药政策

**【2026-10-28】卫生部拟将放射性药品制备列入"高风险"活动类别：风险评分 37 分，与有权制备放射性药品的制剂药房同级，公开讨论至 11-10** — **卫生部**拟修订**2017 年 6 月 29 日第 1049 号政府决议**《药品流通领域联邦国家监督（监管）条例》，相关决议草案**公开讨论至 2026-11-10**。**核心变更**：将**放射性药品（RFLP）的制备**归入**高风险类别**并评定为 **37 分**——该分值适用于**有权制备放射性药品的制剂药房**，以及**开展放射性药品制备的医疗机构**；作为对照，**药品零售**的高风险起点为 **36 分**，**分级表最高分值为 40 分**。**准入含义**：依现行制度，**国家药品流通监督框架下的计划性检查仅针对高风险对象开展**；设立新类别后，放射性药品制备将**首次被纳入计划检查覆盖范围**。**立法理由**：放射性药品含一种或多种**放射性核素**，"因此在其生产中，**药品不合格（如非无菌）会转化为额外的辐射暴露**"。**判读**：本条对中方供应商的直接含义集中在**配套物料**——放射性药品（FDG、锝-99m 标记化合物、碘-131、镥-177 等）的**放射性前体与冷药盒（cold kit）、冻干赋形辅料、无菌过滤器与一次性无菌耗材**对**无菌保证与批放行文件**的要求将随检查密度上升而硬化。需注意本条的适用范围是"**制备**"而非"制剂生产"，**境外 API 出口不在此类别的直接管辖内**，但俄方合作方（如核医学中心、放射性药房）在采购冷药盒与辅料时会更加强调**供应商无菌工艺验证文件**。

**【2026-10-28】地方孤儿药采购的联邦共同融资申请表单获批：卫生部第 820 号令（2026-09-21）正式公布，表单含地区信息与四个实质章节** — **卫生部 2026-09-21 第 820n 号令**已在**官方法律信息门户公布**，批准**联邦主体申请确认需追加联邦预算资金**以保障公民**孤儿病用药**的**申请表单**。**制度依据**：该表单依**2025-11-15 第 1807 号政府决议**制定的规则设计，后者确立了"**确认地区无法独立履行**孤儿病患者药品保障职权"的程序。**表单结构**：含**地区基本信息（抬头）**与**四个实质性章节**。**排除条款**：**属联邦职权保障范围的药品不适用本机制**。**背景**：2025 年 11 月政府已批准**高价孤儿药采购追加联邦补贴**的规则，地区须**同时满足四项标准**方可申请。**判读**：本条是"**孤儿药财政责任的联邦—地方分层**"在操作层面的最后一块拼图——申请表单落地意味着**地区可以实际启动 2027 年度补贴申请**。对中方孤儿药/高值仿制药出口方，其含义是**采购主体将更明确**：属地方职权的孤儿病品种进**地区预算＋联邦共同融资**通道，属联邦职权的品种进**"善之圈"（Krug Dobra）**通道。**两条通道的价格形成机制不同**（前者受地区集中采购与 SZLS 规则约束，后者以基金会单独立项招标），报价与投标策略不能通用。

## 二、医药行业动态

**【2026-10-27】“生物化学”公司巴瑞替尼强制许可经二审维持：第十仲裁上诉法院驳回 Incyte 上诉，年许可费按实际销售额 2.1% 计** — **第十仲裁上诉法院**维持一审判决，**驳回 Incyte Holdings（美国）的上诉**，确认向**“生物化学”（Biokhimik，隶属 Promomed 集团）**授予**巴瑞替尼（baricitinib）**相关专利的**强制许可**，允许其在俄**生产与流通**含该成分的药品。**许可条款**：法院判令权利人**须签署**关于使用**欧亚专利第 017218 号**的许可合同，**年许可费为相关药品实际销售额的 2.1%**。**裁判理由**：依据为**“生物化学”自有开发的技术经济优势**——案卷材料载明，其工艺**可获得杂质更少的巴瑞替尼并提升产量**，但在不使用 Incyte 专利发明的情况下**无法实施**；据此法院认定《俄罗斯联邦民法典》**第 1362 条第 2 款**规定的强制许可条件成立。**程序节点**：**2025 年 8 月**“生物化学”曾向 Incyte 提出签约，**未达成协议**；二审另**驳回 Incyte 关于指定司法鉴定的申请**；本判决可在**两个月内**上诉至**知识产权法院**。**关联先例**：最高法院此前已维持“生物化学”对**兽药“Bravecto”仿制药**的强制许可。**判读**：本条是 10-23 期（“生物化学”诉 ViiV/Shionogi 卡博特韦案胜诉、权利金 1.75%）之后**一个月内的第二例**强制许可胜诉，且**权利金率由 1.75% 上抬至 2.1%**。**趋势判断**：俄法院对强制许可的**"技术经济优势"门槛实际执行口径偏低**（"杂质更少＋产量更高"即足），而**权利金率呈上行**——这意味着**仿制方成本上升但仍远低于自愿许可**。对中方 API/中间体供应商：**巴瑞替尼（JAK1/2 抑制剂）的俄境内仿制产能将由单一企业（Promomed）主供**，其上游**环戊烷并嘧啶类中间体**需求将随本地化放量；同时提示**凡在俄有专利、但本地无人实施或实施不足的品种，均存在被强制许可的路径**——中方若为该专利的权利人（或独占被许可方），须评估俄市场的**强制许可风险敞口**。

**【2026-10-28】国家杜马卫生委员会支持第 1238813-8 号法案（整治医药领域“假学术会议”），拟列入 11-10 杜马工作计划，但要求补充修订** — **国家杜马卫生委员会**表决支持第 **1238813-8** 号法案——打击**医药领域假冒学术会议**，多数委员赞成将文件**列入 11 月 10 日的杜马工作计划**，同时指出**仍需完善**。**主要顾虑**：对医学与药学科研活动设定要求，**不得限制专业界获取知识**；议员并要求**更细致地论证法案的财政经济依据**。**立法空白（提案方陈述）**：现行法律**未界定"科研活动"（会议、研讨会、论坛等）的概念**，**未规定举办程序**，也**缺乏区分真实学术论坛与以学术为名行营利/推销劣质服务之实活动的基本标准**；最危险的情形集中在**医疗机构与制药组织的科研活动领域**——**常有商业机构（往往有外资参与）以"大会""代表大会"之名实施医疗操作**，不仅欺骗消费者，还导致**参与者健康受损甚至死亡**。**佐证案例**：**2025 年 5 月**莫斯科**美容与整形外科"假国际大会"**，卫生监督局检查发现大量**医疗活动许可与医疗服务提供**方面的违法；材料移交**莫斯科中央行政区检察院**并诉至法院，但因**现行法律漏洞，研讨会的主办赞助方与受益方逃脱了行政责任**。**监管方立场**：卫生监督局局长**萨莫伊洛娃**表示，法案通过后该局"**实质上将成为汇集全部科研活动信息的机构**"，但**须同步修订监管立法**——明确**强制性要求**，以对受检对象**分类**（计划检查、抽查、监督性采购），且**该问题须与经济发展部协调**，故建议在修订阶段**强制邀请经济发展部代表参与**。**地方层面**：地区性活动的监管可交由**地方**负责。**判读**：本条对中方企业的含义是**会议合规成本的制度化**——俄方拟建立**科研活动信息归集与分类监管**，一旦落地，**以"学术会议"名义开展的药品推广（含境外厂商赞助的卫星会、专家咨询会）将首次具备可分类、可检查的监管接口**。实务建议：在俄**赞助学术活动、支付讲者费与咨询费**的合规文件（议程、讲者资质、内容审校记录、赞助与内容分离证明）须前置备齐；与**外资参与**的商业办会机构合作尤须做**尽职调查**。

**【2026-10-28】“PSK 制药”称 27 个通用名已进入战略重要药品清单（SZLS），占其组合四分之一；总经理沙皮罗反对将第二部分品种转入第一部分** — 位于**莫斯科州**、**杜布纳经济特区**入驻企业 **“PSK 制药”** 披露其在**战略重要药品清单（SZLS）**中的位置：**27 个通用名（INN）已入列**，**占公司组合的四分之一**。**企业结构**：公司生产**HIV 感染、支气管哮喘、COPD 及多种孤儿病**用药，**按全流程（含分子合成）逐步扩产**，同时瞄准 SZLS 品种与**自有本地化计划**；其策略被评价为"在制剂（GLF）开发阶段即作出正确的组合选择"，故**相当部分组合进入 SZLS**。**制度要点**：SZLS 为"**须在俄实现全流程（含原料药合成）生产**"的药品清单，**分两部分**——**第一部分仅允许全流程生产商参与投标**；**第二部分全流程生产商享有 30% 价格优惠**。**企业主张**：总经理**沙皮罗**建议**不要将第二部分品种转入第一部分**——"**须给行业在当前范式下生存与试错的空间，也让监管方有时间审视全部风险**"；她认为现行方案"**已通过给予全流程生产价格优惠、同时保留制剂生产商参与**来激励本地化，这种竞争**有助于预算节约、让患者获得所需药品**"。**主要风险点**：沙皮罗指出**2026-03-17 第 277 号政府决议第 6 条**——其中存在对"**对周围环境构成危险的疾病清单**"的引用，构成主要风险。**判读**：本条是**俄方"本地化度"考核机制内部张力**的最新一手表述——**监管方倾向把第二部分（30% 价格优惠）并入第一部分（排他投标）**，而**头部本土企业主动反对**，理由是**过度排他会抬高价格、压缩品种供给**。对中方 API 出口方的含义是**双向的**：(a) 若第二部分维持，**制剂生产商仍可投标，其对进口 API 的需求保留**；(b) 若强行并轨，**只有具备俄境内 API 合成能力者才能投标**，**纯 API 出口的通道将被制度性关闭**。**本期为观察窗口，尚无并轨时间表**。—（客户侧变化见 三、重点客户动态）

SZLS 第二部分是否并入第一部分，是纯 API 出口通道的“开关”** — “PSK 制药”披露 **27 个 INN 进入 SZLS**（占组合 25%），并**公开反对**将第二部分转入第一部分；其风险点名指向**2026-03-17 第 277 号政府决议第 6 条**。**制度差异的实质**：SZLS **第一部分＝排他投标（仅全流程生产商）**；**第二部分＝30% 价格优惠（制剂生产商仍可投标）**。**判断**：若并轨，(a) **只有具备俄境内 API 合成能力者**才能进入该等品种的政府采购；**纯 API 出口至俄制剂厂、再由其投标**的路径将**被制度性切断**；(b) 短期可能推高**政府采购单价**（竞争者减少），与“预算节约”的政策目标冲突——这恰是沙皮罗反对的论据。**建议**：密切跟踪**第 277 号决议的修订动态与工贸部/财政部的口径**；对**高依赖 SZLS 品种**的中方客户，**提前评估“俄境内合成＋中国供中间体”的过渡方案**。

**3. 高值生物药的“支付通道”正成为俄市场准入的真实瓶颈，注册并不是主要关卡** — 卡累利阿案例给出的量化证据极具代表性：**GIBP 与靶向药通过 KCG 住院打包付费**，**基础费率不可调、最高系数 1.4 仍触顶**，导致“**药品先进、患者可及性差**”；**资金需求年增 10%—15%**。**叠加本期政策**（地方孤儿药联邦共同融资表单获批）与**存量事实**（“善之圈”依维莫司四轮流标、单价累计上调 3.0%），可形成一个判断：**俄方对高值药的约束已从“注册审批”转向“财政支付能力”**。**对中方生物类似药/高值仿制药的含义**：(i) 进入俄市场的**优先路径是“善之圈”或联邦集中采购**，而非地区自主采购；(ii) **报价须以“可被支付的价位”为上限**，而非以原研价为参照；(iii) **院外/日间/门诊给药**剂型（皮下、口服、长效）在支付上更具优势。

**4. 俄罗斯血液制品与 IVIG 的自给化，对“进口替代”的边界给出新样本** — “Biogam”获批用于**出生第 1 天起**的儿童，是**俄首个层析法纯化的国产 IVIG**，且**儿科此前只能用进口品**。**判断**：(a) 俄方在**血液制品**领域的进口替代**不依赖外部原料**（人血浆自采），因此**该品类不构成中方 API 的机会**；(b) 但**层析介质、除病毒纳滤膜、一次性使用系统（SUS）**等**耗材与装备**的国产化需求随之上升，**这是中方非 API 类切入的相对现实窗口**；(c) **ZhNVLP 内进口 IVIG 的份额将被压缩**，与该品类有贸易敞口的中方贸易商须重估。
