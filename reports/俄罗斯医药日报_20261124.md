## 四、风险提示

**① 俄式"专利折价"证据链已闭合：原研在俄的保护期被系统性压缩（本期升级为高优先级）。** 本期 Promomed×拜耳利伐沙班案确立的司法规则——**"部分无效即整体失效、新专利不构成原垄断的延续、临时保护期内使用不侵权"**——与此前的 **Grotex 恩格列净反垄断处罚（11-20 期）**、**Alium×阿斯利康达格列净"免版税流通换放弃强制许可"和解（11-23 期）** 构成**完整的三条路径**：**行政处罚、司法和解、司法判决**。三者共同指向同一结果：**原研在俄的实际独占期短于名义专利期**。**对中方 API 的传导**：**(a)** 仿制药上市时点前移 → **API 询价的前置期由"专利到期前 12—18 个月"压缩至 6—9 个月**，**提前锁量策略的窗口收窄**；**(b)** 俄方仿制药企业**利润空间扩大**，但**其成本压力会向上游转移**，**API 议价中"专利风险溢价"的合理性下降**，买方将据此要求降价；**(c)** **风险侧**：**原研可能以"第三国诉讼"对冲**（如在本土市场起诉中方供应商的俄方客户），**建议在合同中明确"销售地域限于俄/EAEU，不含原研专利有效辖区"**。

**② 俄方"全流程自产"从化学药向多肽与生物药延伸，对中方 API 的结构性替代加速（本期新增，中高优先级）。** 本期两条同源证据：**Promomed 利那洛肽（14 肽）原料到制剂全流程自产**；**Мабскейл 曲妥珠单抗（自建高表达细胞株）注册**。合读的判断是：**俄方本地化已越过"制剂分装"阶段，进入"原料/上游自主"阶段**，且**载体是少数头部私企（Promomed、Ozon、Pharmasyntez、Geropharm）而非全行业**。**对中方的分层含义**：**(a) 短期（1 年内）**：**大宗化学 API 与中间体的需求仍在**，替代集中于**已在俄有原料合成能力的企业自有品种线**（如利伐沙班 20 家含自合成、利那洛肽）；**(b) 中期（1—3 年）**：**多肽 API（利那洛肽、特立帕肽、奥曲肽）的窗口将逐个关闭**，**GLP-1 类（司美格鲁肽/替尔泊肽）是下一个观察点**；**(c) 对策**：**将俄方采购定位由"替代进口的原料"转为"补充产能的原料"**，**以"俄方产能不足时的增量＋第三国出口配套"为谈判锚点**。
