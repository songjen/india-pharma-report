## 四、风险提示

**1. 生产监督"登记簿化"是本期最需前置应对的制度变更（第 331-FZ 号，2026-12-01 生效）。** 变化的核心不在"多一道手续"，而在于**"是否含 API 合成"成为逐批公开、可被采购方核验的属性**。对纯 API 出口模式的直接冲击是：客户在 SZLS 采购优惠、产业补贴与"俄罗斯制造"认证中所需的"本地化度"证明，将无法再通过制剂分装获得。**建议动作：①在 2026-12-01 前完成主要客户（Biocad 类自产 API 者除外）的工艺阶段申报路径摸底；②对已供品种评估"境外 API + 境内合成最后一步"或"技术转移"两种方案的合规收益与成本；③将 2027-05-01 设为内部决策的最后锚点。**

**2. ZhNVLP 价格重议暂停被否，短期价格通道保留，但"靶向小众药"成为政策敏感区。** 卫生部的反对理由中，"小众靶向药因利润不足而退出"被单独强调，说明**俄方对大宗的成本压力容忍度低于对高值小众品种**。对中国 API 出口方的含义是：大宗仿制药（解热镇痛、心血管、抗生素）仍处在"价格指数化受抑 + 本地替代加速"的双重挤压中，而高值合成品种的相对议价空间更大。**2026-10-20 一读表决结果须纳入次日观察。**

**3. GMP"严重违规"定义收窄，是 2026-12-28 EAEU GMP 新规生效前的风险缓释，但不是豁免。** 草案把"其他不符合项"移出吊销范畴，对境外场地属实质利好；然而"关键/重大"两类的判定边界因此更为清晰、也更难申辩。**建议在 2026-12-28 前完成一次面向第 67 号决议无菌附录与污染控制策略（CCS）的自查**，并将 CAPA 响应窗口（关键/重大不符合项 60 日历日）纳入客户沟通模板。

**4. 重点客户合规事件进入"高频期"：Velfarm-M 与 Velfarm 两周内三起（注册暂停 + 两规格溶出度退市），KRKA 母公司注销 5 品种。** 两类事件的共同指向是**注册档案与工艺的一致性管理**。对 SINOBRIGHT 的启示：**"注册档案一致性文件包"（起始物料来源、合成路线、关键中间体质量标准、稳定性数据）可作为差异化服务产品**，尤其在客户产能与品种结构处于调整期时，其外采决策会更看重供应商的文件支持能力。

**5. 对俄制裁与进口替代监控（本期快照）。**
- **制裁面**：本期未见欧盟/美国新增涉俄医药、API 或化工品出口限制条目。欧盟第 23 轮制裁仍处信号阶段；第 1231 号决议（孤儿药与高技术药品凭外国包装进口一年）已于 **2026-10-11** 生效（见 10-16 期已收录口径，本期不重复）。
