## 四、风险提示

**1. 强制许可制度加速：仿制药上市窗口前移，原研与独家经销的溢价空间被压缩。** 11-18 同日出现三项同向信号——第 1285685-8 号法案一读通过（强制许可之诉集中至 SIP 一审、拟 2027-01-01 生效）、SIP 驳回 Incyte 中止执行（巴瑞替尼 2.1% 费率）、ViiV/盐野义多替拉韦申请搁置至 12-16（费率 1.7%）。**判读**：许可费率 1.7%—2.1% 的量级远低于原研常规毛利，**俄市场仿制药价格战的成本底已可测算**；对以原研或独家代理身份进入俄市场的中国企业，**需重估"专利期溢价"假设**；反之，具备**达格列净、巴瑞替尼、多替拉韦等品种原料药产能**的供应商，其俄需求的可预测性上升。**风险点**：SIP 与普通仲裁法院在"附加专利不诚信"上的裁判尺度若进一步扩大，**可能反向波及中国企业在俄申请的改进型专利**。

**2. 本土 API 产能出现结构性缺口：乌索利耶-西伯利亚化工制药厂面临资产拍卖与破产双线。** 欠税 10.4 亿卢布（约 1,261 万美元）、破产案 11-30 开庭；该厂为苏联时期多个品种的**唯一生产商**，且具备**精神药品与剧毒药品原料药**资质。**判读**：**受控原料药（含麻醉/精神类中间体）的本地供应一旦中断，替代周期以年计**（须重新取得许可与 GMP 认证），短期内只能依赖进口；对中方而言这是**窗口型机会**，但**受控物质跨境合规（出口许可、最终用途证明、国际麻醉品管制局申报）** 的门槛高于普通 API，需前置评估。**★ 提示**：该厂若进入清算程序，其**库存原料与中间体**的处置可能引发灰色渠道流通，**采购端须加强来源追溯**。

**3. 进口替代压力向上游传导：技术平台化扶持与 GMP 名录扩张同向推进。** 工贸部 2027—2036 年制药技术平台计划（试点期 2030 年前、约 250 亿卢布量级）与 15 张新增俄企 GMP 证书，共同指向**"从单品种替代到平台能力自建"**。**判读**：**短期（2027 年前）仍以进口为主**，原料端需求不减；**中期（2027—2030）平台建成后，通用型 API 的本地化替代率将上升**，中国供应商的**议价能力分化**——定制化中间体、高难度手性/多肽片段优于通用大宗。**建议**：对俄客户结构做"通用大宗 vs 定制中间体"拆分，**把增量押在后者**。

**4. 卢布与结算：汇率 82.4529 卢布/美元，与 11-18 持平，但三季度以来累计仍偏强。** 当日俄央行生效价 **1 USD = 82.4529、1 EUR = 90.8136、1 CNY = 12.3419 卢布**。**判读**：卢布偏强对**以美元/人民币计价的进口 API 成本**构成压力，但同时也**抑制了"抢进口"式囤货需求**；对中方出口商，**人民币对卢布的直接结算（1 CNY ≈ ₽12.34）** 可规避美元中间环节，但需关注**俄买方信用证开立与跨境收付通道**的可用性。

**5. 制裁与贸易管制：本期无新增针对性措施，但"平行进口"与"强制许可"两条通道并行，需区分法律风险。** 本期官方与行业媒体未见新的涉俄药品/API/化工品出口限制公告，亦无平行进口清单调整。**判读**：俄方目前**优先使用"强制许可"（本地合法化）而非"平行进口"（跨境灰色化）**解决专利药可及性问题——**前者对供货方的法律风险显著低于后者**，中国供应商若收到俄方"强制许可项下供货"询价，**应要求对方提供 SIP 裁决与许可登记凭证**作为合规依据。
