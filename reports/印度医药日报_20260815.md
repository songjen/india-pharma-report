## 一、政府医药政策

### 【2026-08-11】商工部长 Piyush Goyal：医药列入供应链韧性关键行业；PLI 医药累计销售超 ₹3.64 万亿卢比（$381 亿）（MOCI/Lok Sabha）
商工部长 Goyal 在 Lok Sabha 书面答复中确认，政府将医药与医疗器械列为需强化供应链韧性与进口多元化的关键行业（与能源、化肥、半导体、关键矿产并列）。截至 2026-03-31，PLI 计划共批准 892 项申请、实际投资超 ₹2.4 万亿卢比（$251 亿）；其中**医药板块累计销售超 ₹3.64 万亿卢比（$381 亿），实现 1,931 种产品本土生产，含 191 种首次在印度生产的原料药（bulk drugs），并在 26 个关键 API 品种上建成约 55,000 吨/年产能**。关键矿产也被纳入 FTA 谈判优先事项。

### 【2026-08-11】《药品、医疗器械和化妆品法案 2026》草案披露，医械行业联名反对"按药品模式管理"（卫生部/ET HealthWorld）
8 月 7 日卫生部起草《药品、医疗器械和化妆品法案 2026（草案）》拟取代 1940 年《药品和化妆品法》，8 月 8 日多家医疗器械行业协会联名致信卫生部长反对将医械按药品模式监管：草案拟对标签错误、文档疏漏、工程缺陷等行为设定 1–7 年监禁（即使未造成伤害），并拟赋予药品总监（DCGI）向各邦药监机构发布有约束力指令的权力。草案目前处于部际征求意见阶段。该法将覆盖药品、医械、化妆品与临床试验，是印度 86 年来最大规模的医药监管框架改革。
来源：[ET HealthWorld（经微博转载）](https://weibo.com/ttarticle/p/show?id=2309405331480506400978)

### 【2026-08-10】喀拉拉邦药监局整治药店"误导性折扣广告"，依据 DPCO 价格体系执法（The Hindu）
喀拉拉邦药品管理局依据州药监局长通告（基于喀拉拉高等法院 6 月 19 日裁定）开始对展示误导性折扣广告的药店采取行动，药监检查员获授权检查相关店铺。法院裁定明确：**低于最高零售价销售药品合法、给消费者实际折扣不违法，但禁止展示模糊/误导性的折扣宣传**；NPPA 在 DPCO 2013 下规定受控药品批发/零售利润率 8%–16%（如胰岛素类）、非受控产品 10%–20%。

## 四、风险提示

1. **USFDA 执法升级（8/14）**：Aurobindo 子公司 Eugia Unit I 收到警告信（OAI 后升级），可能影响该厂新 ANDA 审批节奏、增加再检查与潜在 Import Alert 风险；印度制剂出口美企整体合规压力上升；
2. **新医药立法不确定性（8/7-8/11）**：《药品、医疗器械和化妆品法案 2026》草案拟对标签/文档/工程缺陷设 1–7 年监禁，医械行业强烈反对；草案若按此推进将抬高合规成本与刑事风险，部际意见征询期内存在变数；
3. **肿瘤药 API 供应紧张（8/14）**：顺铂/卡铂短缺暴露印度抗癌药 API 供应链脆弱性，NPPA 提价上限后供应仍未恢复，相关 API 厂商（含中国供应商）或迎询单但亦面临价格监管；
4. **美国市场集中度风险**：美国占印度医药出口约 30.9%（Q1 FY27），美关税/地缘政策仍是出口型客户的最大外部变量；
5. **汇率波动**：卢比 8 月中旬回升至 94.4–95.5 区间（5 月危机峰值曾达 96.8），汇率企稳利好出口企业，但若美联储紧缩延续仍存贬值压力。
