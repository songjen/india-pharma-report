## 一、今日摘要

**本期出现本周最重的一份对华医药政策文件，但来自美方咨询机构而非执法机构。** 美中经济与安全审查委员会（USCC）2026 年度报告建议设立 **C2D2（Comprehensive Critical Drug Diversification，关键药品综合多元化）计划**，以美印合作为轴心、以「可核查的原料药/关键起始物料来源」为采购准入条件，并把「证明对中国 KSM 依赖度最低且持续下降」写入对印 API 产能投资的资助条件。这是迄今把「中国 API 链去化」写成可执行资助规则的最完整文本，对 SINOBRIGHT 印度业务属结构性利好、对中国 API 出口属结构性压制。

同步的监管侧动作：FDA 一次性发布 **15 个新草案 + 14 个修订草案产品特定指南（PSG）**，覆盖口服 GLP-1（orforglipron）、K 通道（aficamten）、PI3Kδ（remibrutinib）等新分子与 14 个成熟仿制品种的 BE 要求，是下一轮 ANDA 申报与 API 选品的直接输入。

执法侧（DHS/CBP/BIS 对华清单、OFAC 列名、FDA 警告信、进口警报）本窗口全部静默，无新增涉华医药主体。

**四组条数：① 对华合规/制裁 1 条 ／ ② 双反·关税·337 1 条 ／ ③ 美国医药监管 3 条 ／ ④ 欧盟板块 1 条。合计 6 条；★ 涉清单企业 0 条。**

## 二、① 对华合规法案/制裁（1 条）

### 1. 2026 Report to Congress — Comprehensive List of the Commission's 2026 Recommendations（USCC 年度报告与建议清单）
- **链接**：https://www.uscc.gov/annual-report/2026-annual-report-congress ｜建议清单 PDF：https://www.uscc.gov/sites/default/files/2026-11/Comprehensive_List_of_2026_Recommendations.pdf
- **中文解读**：USCC 在第三章（涉印度章）首条建议设立 **C2D2 计划**，三项支柱——① 建立基本药物供应链预警机制，逐品种登记 API、KSM、关键中间体及其生产地点，识别「单一国家/单一工厂依赖」；② 授权 HHS 设「联邦可信需求计划」，以多年期采购承诺购买「使用合格美国或可信伙伴国 API/KSM 生产」的成品药，并对参与机构统一采购价、赋予调取来源文件的传票权；③ 设立支持印度 API/KSM 产能的公私投资计划，**受资助方须证明对中国 KSM 的依赖度「极低且持续下降」**，并要求印方配套资金、协同印企抵御「中国掠夺性定价」。配套叙事将 API 与稀土、成熟制程芯片、电池材料并列为中国正在复制的「卡脖子」位点。对 SINOBRIGHT：印度作为美方指定的替代供应轴心被制度化，甾体/培南中间体的印度客户将获得美方采购侧的来源溢价，但同时「中国 KSM 依赖度」将成为印方申领美资的合规审计项——中国中间体对印出口的报关与来源文件要求会趋严。
- **时点标注**：报告 PDF 文件时间戳 2026-11-18 06:41（美东），较本期窗口起点早约 12 小时，属**跨窗补载**（依 91 FR 72631 载明的 11-18 提交日）。**性质为国会咨询机构建议，非法律、非行政令，无生效日**。
