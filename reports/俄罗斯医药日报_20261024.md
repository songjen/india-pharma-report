**1. 中俄"药品流通监管合作"入公报，但"本地化生产"方针对纯 API 出口的替代压力同步强化——两条线不可混读。** 联合公报同时写入"支持开展对药品和医疗产品流通的紧密监管合作，坚持最高品质标准"与"进一步明确联合生产方针"（俄方专家解读：中方"进口商应寻找本地化生产伙伴而非仅做分销"）。**建议：①将"标准互认/检查互认"作为 2027 年对俄工作组的议题预备，但不作为近期交付路径预期；②对俄报价模型中，将"本地化生产/技术转移"设为可选方案 B，避免单一纯 API 方案在 2027 年后被边缘化；③肿瘤、内分泌、再生医学三个方向优先准备技术资料包（DMF/CEP 或 CTD 模块 3 级资料）。**
