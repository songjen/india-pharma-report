## 二、医药行业动态

**【2026-10-29】Close-Up 最新口径：巴西处方药市场 12 个月（MAT 08/26）达 R$1,497 亿（≈US$ 27.9 亿），同比 +17.5%；销量 37 亿单位、+5.6%——量价差 11.9 个百分点** — 数据口径为**药房终端消费者价格**，覆盖原研、仿制（genéricos）与类似药（similares）。**结构**：类似药占金额 **42.3%**、数量 **31.7%**（金额 +10.4%、数量仅 +2.0%，**增长几乎全靠价格**）；**仿制药占数量 55.1%**，数量 **+8.2%**（增速居首）、金额 **+20.7%**；**原研药占金额 26.7%，但金额增速最高 +26.6%**——即原研药在 GLAP/创新品种拉动下重新跑赢，与前期"仿制替代加速"的判断形成对冲。**治疗类别**：**糖尿病与肥胖类金额 +54.5%、数量 +14.4%**（量价差 40 个百分点，为全市场最陡）；心血管 +16.1%/+10.7%；中枢神经 +16.8%/+8.4%。**对 SINOBRIGHT 的含义**：① **糖尿病与肥胖类量价差 40 pp** 是本期最硬的量化证据——该品类**增量价值主要来自单价而非用量**，任何以"销量增速"外推原料需求的模型都会系统性低估价格、高估用量；② 原研药金额增速（+26.6%）反超仿制药（+20.7%），说明**专利到期后的替代红利尚未在金额端兑现**，GLP-1 仿制潮对原研的冲击目前仍停留在渗透率层面；③ 仿制药**数量 +8.2% 而金额 +20.7%**，意味着仿制端同样在涨价——这对 API 议价是**有利**信号，但也预示 CMED 下一轮限价压力。 — 来源：[Guia da Farmácia](https://guiadafarmacia.com.br/medicamentos-sob-prescricao-crescem-175-e-movimentam-r-1497-bi-no-pais/)【依据：Close-Up International 数据，MAT 08/2026】

## 四、风险提示

1. **GLP-1 批文密度已超过渠道消化能力**：2026 年累计 **20 支**注射笔，而本批 5 支的 API 全部来自印度（Biocon、OneSource Specialty）。**对中国 API 供应商的直接风险是"被绕开"，而非"被压价"**——须通过**持证方（Aché、Dr. Reddy's 巴西公司、Farma Vision）而非生产方**切入，争取成为其第二来源。
2. **量价结构失衡**：糖尿病与肥胖类**金额 +54.5% vs 数量 +14.4%**，处方药整体量价差 11.9 pp。**以销量增速外推原料需求将持续系统性低估单价、高估吨位**；建议在询价与年度框架中改用"金额×单支 API 用量"双轨核算。
3. **CMED 限价压力正在积累**：仿制药金额 +20.7% 而数量 +8.2%、原研 +26.6%，价格贡献已成市场增长主引擎。**若 2027 年 CMED 调整系数上调，价格传导会被截断**，届时议价压力将直接落到 API 端，建议对长期合同保留**价格调整联动条款**。
4. **配制药房合规风险具象化**：Formédica 因**交叉污染与微生物/职业/环境三项污染**被 90 天查封。配制药房是 API 小额分散采购的主要渠道，**渠道侧突发中断会影响回款**，应将该类客户纳入应收分级监控。
5. **关税与汇率双变量**：USD/BRL 报 **5.36**（10-30 00:02 UTC），较 10-29 的 5.35 微升，**选举冲击后的横盘格局延续**；EMS 成品减重笔关税请求（7.2%→15%）仍未进入 79ª CAT（12-03）公开议程，若落地将把价格竞争重心压向 API 与灌装成本。
6. **高值罕见病药的边际获益须如实标注**：Evrysdi Go 的 2/3 型研究 12 个月 MFM32 仅较安慰剂高 **1.6/100 分**——**弱效证据不应被"首个口服片剂"的剂型叙事掩盖**，在纳入评估与学术引用中应保留该限定。
