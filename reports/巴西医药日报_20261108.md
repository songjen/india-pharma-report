## 一、政府医药政策

**【2026-11-06】ANVISA 发布第 8/2026 号公开征集公告（Edital de Chamamento 8/2026），首次面向巴西境内生产的原料药档案（DIFA）开放独立评估：最多遴选 8 个 DIFA 直接核发 CADIFA（原料药档案适用证书），且不受是否已关联药品注册申请的限制；申报窗口 60 个自然日、结果公示后须 60 日内递交 CADIFA 申请、审评自 2027 年内启动** — 公告由 ANVISA 于 **2026-11-06** 发布。**准入四道硬门槛**：① 原料药须列入公告指定物质清单；② **制造须至少最后一步化学合成在巴西境内完成**；③ 生产厂须持有 **ANVISA 签发的有效 GMP 证书（CBPF）**；④ DIFA 技术文件须符合 **RDC 359/2020** 要求，且**不得已关联在 ANVISA 申报中的制剂注册或变更申请**。**遴选标准**：原料药的本土开发程度、是否参与公共研发创新计划、在巴西境内完成的生产工序范围。**程序时限**：意向表提交期 **60 个自然日**（自公告发布起算）→ 结果于期内结束后 **60 个自然日内**在 ANVISA 门户公示 → 入选企业须在公示后 **60 个自然日内**以事由代码 **11639（CADIFA – Solicitação de CADIFA Não Associada）**递交非关联 CADIFA 申请 → 审评于 **2027 年内**陆续启动。**政策口径**：ANVISA 明确目标是"强化国产原料药生产、**降低对外国供应商的依赖**、发展卫生经济产业综合体（CEIS）"。**对 SINOBRIGHT 的含义**：①⭐ 本条是本期对中方原料出口**最具结构性影响**的政策——它把巴西的 API 监管从"随制剂注册顺带评估"改为"**原料端独立预认证**"，一旦本土企业拿到不关联的 CADIFA，任何后续制剂注册均可直接引用，**本土 API 的注册摩擦成本大幅下降**，进口原料的"合规速度优势"被削弱；② 但**边界同样清晰**：门槛要求**最后一步化学合成在巴西境内完成，且须持本地 CBPF**——这排除了"仅分装/精烘包"的取巧路径，也意味着该通道**只对真正落地合成的产能有效**，短期内（2027 年前）对进口格局的实际冲击有限；③ 对我方的直接提示是**优先级判断**：该政策指向的具体物质清单目前只在公告附件中（门户链接受 Cloudflare 校验未能读取），**须在下一期以官方附件核实清单是否覆盖培南类、甾体激素或常见仿制药 API**——若覆盖，则应提前评估"**在巴落地最后一步合成 + 合资/受托生产**"的政策诱因（补贴、PDP 采购优先）是否足以抵偿成本；④ 与我方主线的**反向机会**：本土产能若聚焦于清单内的"高政策价值品种"，则清单外的中间体（MAP/4-AA 等）仍须依赖进口，**我方优势品种反而可能因资源再分配而巩固**；⑤ 本条亦与 **11-11 Sindusfarma/Datafolha 全行业普查**同向——二者共同构成巴西"摸清进口依赖底数 + 建立本土预认证通道"的政策组合。 — 来源：[ANVISA](https://www.gov.br/anvisa/pt-br/assuntos/noticias-anvisa/2026/anvisa-abre-chamamento-para-avaliacao-de-insumos-farmaceuticos-ativos-produzidos-no-brasil)【依据：ANVISA Edital de Chamamento nº 8/2026（2026-11-06 发布，公告 2026-11-06 21h13）；RDC 359/2020；事由代码 11639】

**【2026-11-06】ANVISA 依据 Resolução-RE nº 4.329/2026 查扣并禁售假冒 Mounjaro（替尔泊肽）5 个批次，同时查扣 7 个未注册 Pygeum 植物药品牌及未注册的抑菌稀释液/抑菌水；假冒批次由原研 Eli Lilly do Brasil 主动上报** — 决议 **2026-11-04 签署**，**2026-11-06 刊于《联邦官方公报》**，ANVISA 同日下达查扣令。**假冒批次清单**：Mounjaro 2,5 mg（批号 **KUSTR43969410**）、5 mg（**B55010**）、15 mg（**D810042、D838889、2138737**）。**判定依据**：Lilly 报告存在**非本公司生产记录的批号**，且**标签与厂商生产标准不符**；报道另指其中 **D810042 属真实生产批次**，禁令仅针对已识别的假冒单品，不波及正品。**同案处理**：Pygeum 植物药（Oficialfarma、Unicpharma、Bioformulas、Swanson、Recover Farma、Nutricost 六个品牌及无品牌装）与"抑菌稀释液""抑菌水"因**未获药品类别注册**，一并禁止生产、分销、销售、广告、运输与使用；ANVISA 援引 **Lei nº 6.360/1976**。**对 SINOBRIGHT 的含义**：① 本条属**执法类**信息，对 API 贸易无直接商业含义，但其**风险指向明确**——GLP-1/GIP 类已是巴西假药最集中的品类，**年内第二次**针对该品类发布假冒通报（前次见 10 月期记录），说明**需求缺口 + 高单价**正在持续吸引灰色渠道；② 对我方的实操含义在**供应链尽调**：若客户（含配制方、小型分销商）以"平行采购"名义询价替尔泊肽/司美格鲁肽原料，须核实其**是否为已注册持证方或其授权加工方**，否则一旦上游批次被认定为来源不明，**供应方将被一并纳入调查范围**；③ 与本日第一板块的 **DIFA 独立预认证**形成对照：巴西正在**同时收紧灰色端（假冒/未注册）与开放正规端（本土 DIFA 预认证）**，合规路径的"窄门"效应强化；④ **不应将该执法事件解读为原研份额回升**——11 月 6 日 Novo CEO 已公开承认在巴"丢失份额"（见第二部分），假冒治理与份额结构属两条独立线索。 — 来源：[ANVISA](https://www.gov.br/anvisa/pt-br/assuntos/noticias-anvisa/2026/anvisa-proibe-lotes-falsificados-de-mounjaro)【依据：DOU Resolução-RE nº 4.329，2026-11-04 签署、2026-11-06 刊于 DOU；ANVISA 公告 2026-11-06 09h29】

## 二、医药行业动态

**【2026-11-07】Dr. Reddy's 获 ANVISA 上市许可，其司美格鲁肽仿制注射液（每周一次，预充多剂量注射笔 2 mg/1.5 mL 与 4 mg/3 mL）获批用于二甲双胍不耐受或禁忌者的单药治疗及联合治疗；公司明确将与 Aché 合作在巴上市，并给出巴西糖尿病适应症司美格鲁肽市场规模约 US$ 2.446 亿、巴西 20–79 岁糖尿病患者 1,660 万（全球第六）** — 批准由 **Dr. Reddy's 于 2026-11-06 至 11-07 对外公布**，ANVISA 端未在门户首页单列该条（故本期以企业公告为一手来源）。**产品规格**：**2 mg/1.5 mL** 与 **4 mg/3 mL** 两种预充多剂量笔，**每周一次**给药；适应症为**成人 2 型糖尿病血糖控制不佳者**，作为饮食与运动的补充；可在**二甲双胍不耐受或禁忌时单药使用**，亦可与其他降糖药联用。**管理层表态**：全球仿制药业务 CEO **MV Ramana** 称"在巴将与 **Aché** 共同上市"。**市场口径（须区分）**：企业口径为**糖尿病适应症**市场约 **US$ 2.446 亿**；印度媒体另引 **IQVIA 2026 年 6 月**数据称**巴西司美格鲁肽注射液整体市场约 US$ 4.13 亿**（含减重用途）——**两者统计范围不同，不可混算**。**同业背景（同源报道）**：Sun Pharma 已于 **2026 年三季度**经 **Hypera** 在巴上市仿制司美格鲁肽；Dr. Reddy's 此前因**印度生产端 API 杂质问题**导致供应中断，公司称**本月恢复供货**。**对 SINOBRIGHT 的含义**：①⭐ 本条补上了巴西 GLP-1 竞争的**最后一个拼图——印度多肽制剂方与本土渠道方（Aché）的绑定**：迄今在巴的司美格鲁肽供给已形成 **EMS（自产仿制 + SemaClique 装置）/ Hypera–Sun / Aché–Dr. Reddy's** 三条独立链，价格战的组织形式已从"多品种"进入"**多国供给方 × 本地分销方**"的结构；② 对我方的含义在**上游资质门槛的确认**：Dr. Reddy's 的供应中断直接由 **API 杂质**引发，说明在巴西 GLP-1 赛道中，**原料端的批次纯度与变更控制已成为制剂方能否履约的决定变量**——这与 11-03 期记录的 **Sinopep-Allsino（诺泰生物）连云港 CBPF** 形成正反两面证据；③ 对**非多肽主线**（培南中间体、甾体）的间接影响：本土头部企业（EMS、Hypera、Aché）的资本与管理注意力进一步向 GLP-1 集中，**传统品类的采购谈判将更趋成本导向**，我方应以**稳定供应 + 账期**替代关系型议价；④ 须注意**"获批"≠"已上市"**：本条为上市许可，**定价与上市时点未公布**，CMED 定价将是后续价格锚。 — 来源：[Indian Pharma Post](https://www.indianpharmapost.com/regulatory/dr-reddys-receives-brazil-approval-for-generic-semaglutide-injection-22345)【依据：Dr. Reddy's 上市许可公告（2026-11-06 发布，2026-11-07 报道）；MV Ramana（Global Generics CEO）表态；市场规模为企业口径 US$ 2.446 亿（糖尿病适应症）与 IQVIA 2026-06 口径 US$ 4.13 亿（整体注射液），二者范围不同】

## 三、风险提示

1. **本土 API 预认证通道开启，进口原料的"合规速度差"将被压缩**：ANVISA Edital 8/2026 允许**不关联制剂注册**的本土 DIFA 直接申请 CADIFA，最高 8 个名额、60 日申报、2027 年内审评。门槛要求"**最后一步合成在巴西境内 + 本地 CBPF**"，故短期（2027 年前）对进口格局冲击有限，但**方向明确**：巴西正把 API 监管从"跟随制剂"转为"独立预认证"。**我方须在下一期核实公告附件中的物质清单**，若覆盖我方主线品种，应立即评估"落地最后一步合成"的政策诱因（PDP/CEIS 采购优先、BNDES 融资）与成本。
2. **GLP-1 在巴西已确认为"纯价格竞争"市场，且增长拉动进入递减段**：原研 CEO 公开表示"就是价格、价格、价格"且选择不跟底价、**丢掉份额**；新兴市场板块 3Q −3%。同期 Panvel GLP-1 增速 68.8%（早期为翻倍）、Pague Menos 对增长贡献降至 2.0 pp、Itaú BBA 明确"比较基数变难导致自然减速"。**三条独立来源同向，可判定该类品种的价格谈判空间已实质消失**；若我方涉及多肽以外的替代品类，**不得以 GLP-1 毛利水平外推整体 API 定价**。
