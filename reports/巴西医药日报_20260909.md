## 一、政府医药政策

**【2026-09-08】ANVISA 主席：2026 年底前拟再批 8 个 GLP-1 减重笔注册（年内已批 6 个、13 个在审）；Conitec 否决减肥笔进 SUS** — 主席 Safatle 记者会表示，将采用优化审评模式加速多件注册并行评估，年内已批 Ozivy、Zempneo、Semavy、Orsema、Seemasun、Owozy 6 个司美格鲁肽笔（13 个在审、其中 1 个预计本月完成），以扩充正规供给、挤压经巴拉圭边境走私的非法市场（联邦警察查获量上升），并拟与巴拉圭卫生当局签署信息共享 MOU；另 Conitec 以预算冲击超 R$80 亿（约合 USD 15.7 亿）为由否决将减重笔纳入 SUS。— 来源：[WorldScope News](https://www.worldscope-news.com:2083/en/world/anvisa-expects-to-approve-eight-more-weight-loss-pen-brands-by-2026)

**【2026-09-04】巴西禽肉与蜂蜜对欧出口恢复进程推进（MAPA 审计完成）** — MAPA 宣布欧盟卫生审计于 9/4 完成，巴西朝重回欧盟禽肉/蜂蜜供应商名单迈进；系 9/3 欧盟限制生效后官方层面首次明确恢复信号，后续牛肉/水产等品类合规谈判仍待推进。— 来源：[MAPA](https://www.gov.br/agricultura/pt-br/assuntos/noticias/brasil-avanca-na-retomada-das-exportacoes-de-aves-e-mel-para-a-ue)

## 四、风险提示

1. **GLP-1 批文潮再提速**：ANVISA 明确年底前再批 8 个减重笔（现有 6 个 + 13 个在审），多肽 API 需求持续上行，但供给竞争白热化 + 仿制药强制 35% 折价持续挤压终端价格，API 供应商利润空间取决于 DMF 完备度与质量体系。
2. **SUS 报销缺席、零售渠道为王**：Conitec 否决减重笔纳入 SUS（R$80 亿预算冲击），市场放量依赖 CMED 定价后的院外自费零售——对 API 采购方的价格敏感度与订单节奏影响需跟踪。
3. **走私与非法市场并存**：巴拉圭边境走私减重药查获量上升，ANVISA 拟与巴拉圭签 MOU 强化信息共享；正规仿制放量将压缩灰色渠道空间，也带来市场监管不确定性。
4. **欧盟兽用抗菌药合规外溢**：Reg 2019/6 条款对巴西动物源产品出口的限制生效，巴西兽药/动物保健监管趋严趋势明确——涉兽用抗生素（含中国 API/中间体供应）业务需关注巴西对标欧盟的抗菌药管理新规。
5. **Gecex/汇率变量**：USD/BRL 5.09 处近期低位区间波动，Gecex 关税审议与对华贸易政策仍是 API 入巴成本的潜在变量。
