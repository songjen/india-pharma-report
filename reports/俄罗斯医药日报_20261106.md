## 四、风险提示

**① 俄方公开承认"无力与中国、印度比拼原料药规模"，这是中方 API 的结构性利好，但须与"70% 国产化"主张的风险面对冲看待。** ChemRar 政府关系总监在"Биопром"论坛明言：**仿制药段比的是成本与规模**，**俄企无力与数十年建立原料药规模优势的印度、中国竞争**；并主张将战略指标改为**2030 年国产药占比不低于 70%、其中自有专利创新药不低于 30%**（现指标 42.6% 已于 2025 年以 46% 达成）。**含义**：**(a) 俄方的"国产化"实质是"制剂国产化 + API 外购"**，中方 API 需求**不因替代而消失，反而随制剂放量而增长**；**(b) 但"创新药 30%"目标一旦入战略，资源将进一步向生物药与细胞/基因治疗倾斜**，**通用小分子 API 的公共支持边缘化**。**建议**：把**"俄方已国产化制剂、但 API 外购"的品种**作为主攻方向（参见本期 Part B "40 个 ЖНВЛП INN 国产化清单"），**不以"制剂出口"为目标**。

**② 俄政府采购正在以"提价成交"应对超罕见病供给集中，单价信号可作为议价参照，但不可外推至常规品种。** 本期"善之圈"利司扑兰两标段**合计 38.35 亿卢布（约 4,691 万美元）、单价 316,428.58 卢布/g**；对照 11-03 期依维莫司**983.58 卢布/片**（第四次提价后成交）。**含义**：**超罕见病与单一来源品种的买方几无议价空间**，而**常规品种（尤其多来源仿制药）价格仍在竞争性下压**。**建议**：对俄报价按**"单一来源／多来源"两套模型**分别设定——前者**锚定政府采购最高限价**，后者**锚定竞争者报价与汇率带**；**切勿以孤儿药单价推断大宗 API 价格空间**。

**③ 单一来源进口药断供的临床风险正在显性化，构成中方"仿制＋注册"的窗口，但周期长、不宜作短单预期。** 本期"Элидел（吡美莫司）"在**65 个以上地区**断货、**1—9 月采购额降 34%、包装量降 37%**，且**3 个月—1 岁婴儿已无替代**（多数糖皮质激素禁用于 1 岁以下）；叠加 11-04 期"ALS 患者获未注册药 Qalsody"的司法确认、11-05 期"MSD 停供 Зепатир"。**含义**：**"唯一注册＋指南依赖＋特殊人群"三重叠加的品种最易断供**，也最可能获得**加速注册或个体进口的松动**。**建议**：**(a)** 建立"**俄境内单一来源注册品种**"清单（可从国家药品注册簿按 INN 计数为 1 者筛出），**逐项比对中方已有批文的品种**，形成**候选名单**；**(b)** 对此类机会按**12—18 个月注册周期**排期，**不做现金流承诺**。

**④ 含酒精药品清单与生物等效性规则的两项"松绑"，共同指向"外用与酊剂类制剂"的注册放量，这是本期最具操作性的机会线索。** 政府**第 3192-р 号令**新增 **30 项**含酒精药品（**酮咯酸、双氯芬酸凝胶、萘替芬喷剂、苯达明、2% 亮绿溶液**等）**不再适用酒类管制法**；**ЕЭК** 允许**软膏与凝胶皮肤渗透研究以人造膜替代人皮**，**官方明示将降低仿制药开发成本**。**含义**：**外用半固体制剂的注册成本与周期双双压缩**，**俄方外用仿制药数量预计 2027 年上行**。**建议**：锁定**激素类（糠酸莫米松、丙酸氯倍他索）、抗真菌类（特比萘芬、酮康唑）、NSAIDs 类（双氯芬酸、酮洛芬）** 的 **API 与透皮促渗辅料（丙二醇、氮酮、卡波姆）**，**提前布局俄方客户的注册文件支持**。
