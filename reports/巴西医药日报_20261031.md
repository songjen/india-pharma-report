## 一、政府医药政策

**【2026-10-29】ANVISA 第 20 次公开例会：特殊管制处方电子化过渡期由 10 月底延至 2027-03-03；同时启动国产原料药档案（DIFA）公开征集，最多遴选 8 份、2027 年内完成审评** — 10-29 18:51 公告。**① 处方电子化延期**：董事会一致通过修改 **RDC 1.000/2025**，将**特殊管制处方（RCE）与须留存处方（RET）**在**国家处方管控系统（SNCR）**内的过渡期由此前的 **2026 年 10 月**延长至 **2027 年 3 月 3 日**（报告人 Thiago Campos）。官方披露进度：新格式自 **2026-09-30** 上线以来已发放 **逾 2.74 亿个唯一编号**，生态（处方者／电子处方平台／调剂机构）处初期采用阶段；延期理由是完成技术与操作适配、延长系统稳定性观察期、降低患者用药中断风险。**② 国产原料药档案（DIFA）公开征集**：批准启动 **Edital de Chamamento**，遴选**至多 8 份在巴西境内生产的原料药档案（DIFA）**，专门针对**尚未关联任何药品注册或注册后申请（petições de registro/pós-registro）**的原料药进行独立技术审评，分析工作于 **2027 年**全年完成（报告人 Daniela Marreco；Daniel Pereira 附议）。官方定性为**强化 CEIS 卫生经济产业综合体、降低对外国供应商依赖、保障危机与紧急状态下的药品供应**，并明确其目的在于为**想在巴西做原料药的企业提供法律确定性与监管可预期性**。**③ 其他议题**：2027 年南半球流感疫苗株与 2026/2027 北半球株组分更新（IN）；IN 211/2023（食品添加剂）、IN 87/2021（植物油）更新；**药学等效中心检查路线图**进入公开咨询；撤销 RDC 184/2017（农药毒理 SIPTOX，非药品）。**④ 人事风波**：董事会对 Daniela Marreco 因 polilaminina 研究遭网络攻击表态支持，ANVISA 于 10-22 发布澄清公告。**对 SINOBRIGHT 的含义**：① DIFA 征集是巴西**首次**为「无注册绑定的原料药」单设审评通道，虽限于**境内生产**，但其技术标准与审评口径一旦成型，将**反向成为进口 API 的参照基准**（GMP 档案颗粒度、稳定性与杂质谱要求），建议持续跟踪最终遴选名单与公告细则；② 该项与 10-28 期 BNDES 对 Althaia 的 R$ 2.98 亿（含 20 个首仿）、10-30 期 Close-Up 显示的**仿制药金额 +20.7%** 构成同一方向——**巴西本地化产能扩张正在被政策与资本双轮推动**，中国 API 在巴的角色将更多转向「本地灌装的上游供应」而非成品替代；③ 处方电子化延期一个月余，对特殊管制药品（含麻醉、精神类 API 下游制剂）的**销售与流向数据统计**将出现过渡期口径混杂，短期不宜用 SNCR 数据做渠道推断。 — 来源：[ANVISA](https://www.gov.br/anvisa/pt-br/assuntos/noticias-anvisa/2026/20a-reuniao-ordinaria-publica-da-anvisa-periodo-de-transicao-para-emissao-de-receitas-eletronicas-no-sncr-e-prorrogado)【依据：ANVISA 第 20 次公开例会决议 2026-10-29；RDC 1.000/2025 修订】

## 三、重点客户动态

## 四、风险提示

1. **巴西原料药本地化正从"口号"转为"制度"**：ANVISA 首次为**无注册绑定的国产原料药档案（DIFA）**单设审评通道（至多 8 份、2027 年审评），叠加 BNDES 对 Althaia 的 R$ 2.98 亿（含 20 个首仿）与 CEIS 框架。**中期风险是进口 API 的技术门槛被抬高**——DIFA 形成的档案标准会外溢为进口审评的参照，建议提前按该颗粒度准备 GMP 与稳定性文件。
2. **GLP-1 价格战已在原研端展开，且以量补价成立**：Lilly 国际市场价格 **−29%**、全球量 **+53%**，毛利率反升至 83.9%。**仿制端（Semavy 等）的价格空间将被持续压缩**，API 采购端承受的降价压力会在 2027 年度框架谈判中集中释放；同时须警惕「降价→需求萎缩」的错误外推，用量仍在增长。
3. **Semavy 适应症限于 T2DM 的事实必须贯穿所有需求测算**：首月 9.3 万支的放量属糖尿病市场，**不构成肥胖市场的需求证据**；若按肥胖人群外推司美格鲁肽 API 吨位，将系统性高估。
4. **印度供应商正以本地法人形式进入巴西**：Granules 设立 Triton Farmacêutica do Brasil。**竞争维度从价格转向"本地实体+分销网络"**，单纯依靠报价优势的路径将逐步失效；建议将「本地代理/合资」纳入 2027 年巴西策略选项。
5. **SUS 高值药准入转向"分层+二线限定"**：iptacopan 被限定为 C5 抑制剂治疗后仍贫血者的**二线**，且首次明确披露 eculizumab **年费 R$ 125 万/人**。**二线位置的准入价值上升 → 首仿/类似药的机会前移**，但单品天花板同时被限定，不宜按全人群测算。
6. **汇率加速走弱**：USD/BRL 报 **5.40**（10-31 00:02 UTC 5.3972；10-30 收盘 5.4325），较 10-30 的 5.36 继续贬值约 0.6%，10 月内自 5.03 累计贬值约 7%。**以 R$ 计价合同的实际美元收入持续被侵蚀**，建议新签合同加入汇率联动或缩短报价有效期。
