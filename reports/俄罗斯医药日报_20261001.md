## 四、风险提示

1. **对俄制裁与进口替代监控**：本期无新增制裁/清单类公告。西方药企在 2022 年后持续不向俄市场投放新药，已由 ChemRar 总裁公开确认为行业结构性事实，并成为俄方"以中国等非西方国家创新品种填补缺口"的直接动因（本期 ChemRar×轩竹 bireociclib 早期准入即为首个落地案例）。★ 涉制裁企业：本期无新增命中。

2. **【重点】麻醉止痛药原料药（API）本地化时间表确立，构成明确的替代窗口**：副总理戈利科娃宣布 2030 年前在俄建设**麻醉类止痛药原料药生产厂**，且已确认当前止痛药制剂生产实现"国内原料保障"。结合 2026-12-01 起 30% 价格优惠机制与工业产品登记册（RPPP）评分门槛，麻醉/精神类 API 及其关键中间体是最先被行政力量锁定本地化的细分。**对中国供应商的含义**：① 麻醉类 API 属受控物质，跨境贸易受《1961 年麻醉品单一公约》及中俄双边管制约束，直接出口通道狭窄且合规成本高；② 可行的切入路径仍为**为俄本土工厂提供非受控中间体与前体工艺**，或以技术授权/代工形式参与：③ 2030 年为明确终点，2027—2028 年为设备采购与工艺验证窗口期，供应商宜在此前完成俄方客户的注册与技术对接。

3. **【重点】碳青霉烯类"佐剂强化"路径对 SINOBRIGHT 培南业务的含义**：俄三校的色酮类佐剂可使美罗培南剂量降低 64 倍、多立培南降低 16 倍。若进入临床，**单位制剂的美罗培南原料用量将大幅下降**，理论上压缩培南 API 的需求总量；但该效应同时会被"恢复储备抗生素对耐药菌的可用性 → 临床使用范围扩大"部分对冲，且该研究仍处实验室阶段、距商业化尚远。**建议**：将色酮类佐剂列入中期技术观察项（与 09-24 期同一研究，本期为定量数据补充），不作为近期采购规划变量；同时关注其配套佐剂是否形成新的原料需求。

4. **【重点】原研药"量额背离"加剧，仿制药替代已越过价格拐点**：RNC 抗凝药数据显示，1—8 月销量 +15.9% 而金额仅 +2.8%，>3.5 千卢布高价档连续两年萎缩（额 -8%），<1 千卢布低价档由利伐沙班仿制药驱动额 +28%、量 +30%。原研 Eliquis +4% / Xarelto -19% 的分化表明：**原研品牌在俄市场的价格溢价正在被系统性削弱**。对上游 API 供应商的含义是——利伐沙班、阿哌沙班等**仿制药用原料药的需求份额持续上升**，而供给该原料的竞争焦点将转为成本与产能而非专利壁垒；同时阿哌沙班在俄专利 2027-02 到期，是与利伐沙班同样的下一轮放量品种。

5. **兽药线上渠道监管收紧延续**：后贝加尔边疆区封禁 300 余个无证兽药网站，且重点扫描大型电商平台。结合 09-27 期已记录的"线上渠道占兽用添加剂零售额 50.9%"与 Rosselkhoznadzor 夏季提交的严控提案，俄兽药/兽用投入品的**线上销售合规成本正在抬升**；对出口商的含义是渠道合规尽调应前移，避免因下游经销商被查导致货款与合规连带风险。
