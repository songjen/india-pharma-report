## 二、医药行业动态

**【2026-10-18】Venus Remedies 在四国获五项上市许可，含阿根廷美罗培南** — 印度危重症注射剂企业 Venus Remedies 获哈萨克斯坦万古霉素与氟尿嘧啶、秘鲁氟维司群、科威特甲氨蝶呤、阿根廷美罗培南五项上市许可，覆盖独联体、拉美与中东；公司产品已进入 100 多个国家，称将以注册与差异化品种继续扩张出口。 — 来源：[Indian Pharma Post](https://www.indianpharmapost.com/news/venus-remedies-receives-five-marketing-approvals-in-kazakhstan-peru-kuwait-argentina-22181)【依据：公司公告 2026-10-18】

**【2026-10-15】印度 API 市场 2031 年预计达 221.8 亿美元，本土替代为主线** — 券商研究预计印度 API 市场规模至 2031 年达 221.8 亿美元；Laurus FY26 API 收入 ₹2,746 crore（同比 +13%）、小分子 CDMO ₹1,896 crore（+38%），累计 DMF 92 项，FY26 资本开支 ₹1,070 crore；Divi's 有 30 个商业化通用名 API。 — 来源：[Financial Express](https://www.financialexpress.com/market/stock-insights/indias-api-market-could-hit-22-18-billion-by-2031-3-pharma-stocks-to-watch/4363281)

**【2026-10-17】阿斯利康启用孟买新公司办公室，在印临床研究约 80 项** — 新办公室 25,600 平方英尺，由马哈拉施特拉邦首席部长揭幕；公司近三年在印引入逾 25 个新药与适应症，约 80 项全球临床试验在印开展，在印员工近 5,000 人，重点投向肿瘤、生物制剂与罕见病。 — 来源：[Indian Pharma Post](https://www.indianpharmapost.com/news/astrazeneca-opens-new-mumbai-corporate-office-22176)【依据：公司公告 2026-10-17】

## 三、重点客户动态

**【2026-10-18】LUPIN 获 CDSCO 批准 nivolumab 生物类似药，原料药与制剂同时获批** — Lupin 获准生产销售 BMS Opdivo 的生物类似药，覆盖原研全部 12 项适应症，须开展 IV 期研究；本次同时获批制剂与原料药，由海得拉巴 CDMO Virchow Biotech 合作生产。Zydus（1 月，Tishtha）与 Dr. Reddy's（9 月，Nivorz）此前已上市，印度免疫肿瘤市场约 ₹3,900 crore。 — 来源：[ET Pharma](https://pharma.economictimes.indiatimes.com/news/drug-approvals-and-launches/lupin-gets-cdsco-nod-for-nivolumab-biosimilar/135025868)【依据：CDSCO 批准，2026-10-18 报道】
