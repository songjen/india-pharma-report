## 四、风险提示

1. **GLP-1 仿制潮的结构性机会与挤压并存**：司美格鲁肽专利 2026-03 到期后批文加速（7 月 5 笔 + 8 月 3 笔），多肽 API 需求上行；但 CMED 限价 + 仿制药强制 35% 折价挤压终端价，API 供应商议价空间取决于质量体系与 DMF 完备度。
2. **Gecex 关税/贸易救济入口活跃**：TEC 调整与反倾销动议常态化，中国 API/中间体入巴需跟踪 Gecex 对 HS 29/30 章税号的变动。
3. **中巴/印巴双线竞争**：印巴贸易 7 个月 101 亿美元（+32.9%）+ ApexBrasil-印度合作协议（8/26），印度 API 份额增长可能挤压中国供应商。
4. **注册互认版图扩大**：墨西哥承认 ANVISA 评估（45 个工作日简化路径）——"巴西注册→拉美延伸"模式成形，对中资 API 是双国注册协同机会，也是竞争门槛（注册资产更值钱）。
