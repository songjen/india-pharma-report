## 一、政府医药政策

**【2026-09-02】ANVISA 公布：8/20 授权 Fiocruz/Biomanguinhos 开展国产 mRNA Covid 疫苗 I 期临床** — ANVISA 授权奥斯瓦尔多·克鲁兹基金会（Fiocruz）开展 COVID19 (mRNA) 疫苗（Biomanguinhos 开发）的 **I 期临床研究**，评估在健康成人中作为加强针（booster）的安全性与免疫原性；若成功，该疫苗将成为**巴西首个国产 mRNA 疫苗**。临床方案登记于 Clinicaltrials.gov（NCT07640308）。含义：巴西 mRNA 平台能力建设提速，生物药/疫苗本地化趋势强化（与 PDP 计划呼应）；对 API 出口商是"巴西本土化加深"的又一信号。— 来源：[ANVISA 官网（直连）](https://www.gov.br/anvisa/pt-br/assuntos/noticias-anvisa/2026/anvisa-autoriza-estudo-clinico-da-fiocruz-com-vacina-de-mrna-para-covid)

**【2026-09-03】墨西哥 Cofepris 互认 ANVISA 监管决定，创建简化药品注册程序（45 个工作日）** — 墨西哥联邦卫生风险保护委员会（Cofepris）发布新指南：承认 ANVISA 的评估要求/测试/程序等效，凡已获 ANVISA 批准的新分子、仿制药、创新生物药、生物类似药及生物制品/疫苗，向墨方提交完整文件后可**免除重复技术评审**，墨方最长 **45 个工作日**作出决定（原流程可能耗时数年）。前提：送墨产品关键特征与巴西批准一致、巴西注册在有效期内。对 API/制剂出口商含义：**获得 ANVISA 注册的产品可沿此互认路径低成本延伸进墨西哥市场**——巴西注册的"价值外溢"增强，中资 API 若同时布局两国注册可享协同。— 来源：[ANVISA 官网（直连，2026-09-03 08:05 发布）](https://www.gov.br/anvisa/pt-br/assuntos/noticias-anvisa/2026/mexico-reconhece-decisoes-regulatorias-da-anvisa-e-cria-procedimento-simplificado-para-registro-de-medicamentos)

**【2026-09-02】ANVISA 批准"合成/半合成药品注册质量分析优化试点"（IN，第 16 次董事会）** ⭐ — 为落实削减注册排队计划，ANVISA 于 9/2 第 16 次董事例会通过 IN（指令），启动合成/半合成药品注册申请的质量分析优化试点：基于 **REQ（Resumo Estruturado da Qualidade，结构化质量摘要）** 工具，将质量卷宗关键信息结构化，辅助 GQMED（合成药质量审评处）决策，缩短信息定位与评估耗时；不降低/不替代现行技术标准，不改变完整卷宗要求。含义：**合成/半合成类（含仿制药 API 制剂）注册审评提速**，排队削减；对 API 出口商是正面信号——注册文件（DMF）完备、质量数据结构化的供应商将先受益。— 来源：[ANVISA 官网（直连，2026-09-02 11:32 发布）](https://www.gov.br/anvisa/pt-br/assuntos/noticias-anvisa/2026/anvisa-aprova-analise-otimizada-para-registro-de-sinteticos-e-semissinteticos)

**【2026-09-04】MDIC 开启"监管改善行动计划 2030"公众参与（截至 9/18）** — 巴西发展工业外贸部通过 Brasil Participativo 平台征集对《国家监管改善战略 2027-2030 行动计划》的意见，涉及药品注册等监管流程的简化方向。— 来源：[MDIC 官网（直连）](https://www.gov.br/mdic/pt-br/assuntos/noticias/mdic-abre-participacao-social-para-definir-acoes-de-melhoria-regulatoria-ate-2030)

**【2026-08-27】Gecex 审议关税调整与贸易救济措施（CAMEX 决策层）** — 巴西外贸委员会执行管理委员会（Gecex）例会审议 TEC 关税调整及贸易救济（反倾销/保障措施）动议；虽本期议题为石油出口税延期 60 天，但该机制是 API/中间体进口关税与反倾销调查的决策入口，建议持续跟踪其对药品 TEC 税号的调整。— 来源：[MDIC/CAMEX 官网（直连）](https://www.gov.br/mdic/pt-br/assuntos/noticias/2026-periodo-eleitoral/agosto/gecex-delibera-sobre-alteracoes-tarifarias-e-defesa-comercial)

**【2026-09-02】MAPA 8 月投放 990 万剂抗梭菌疫苗（国产+进口）** — 巴西农业畜牧部公布 8 月兽用梭菌病疫苗投放平衡表，涵盖国产与进口产品，是兽药/动物保健板块的官方供给信号。— 来源：[MAPA 官网（直连）](https://www.gov.br/agricultura/pt-br/assuntos/noticias/2026/09/mapa-disponibiliza-99-milhoes-de-doses-de-vacinas-contra-clostridioses-em-agosto)

## 四、风险提示

1. **⚠️ 巴西官方一手信息获取路径（已实测打通）**：gov.br 基于 Plone CMS，ANVISA `noticias-anvisa` 列表页为 JS 渲染空壳（勿抓），**门户首页新闻区块静态可抓**；卫生部列表可达但噪音极大（本期 13 条全为移动医疗车服务类）；`site:gov.br` 外部搜索索引覆盖差。**可靠路径 = 官网直连（首页区块/新闻列表）+ DOU/RE 决议号溯源**。对 API 出口商：注册/反倾销政策变化仍可能先见媒体后见官方，需双轨盯梢，但官方一手段已验证可用。
2. **GLP-1 仿制潮的结构性机会**：司美格鲁肽专利 2026-03 到期后，巴西批文节奏明显加快（7 月 5 笔 + 8 月 3 笔），多肽 API 需求上行；但 CMED 限价 + 仿制药强制 35% 折价将挤压终端价，API 供应商议价空间取决于质量体系与注册文件（DMF）完备度。
3. **Mercosur 关税/贸易救济入口（Gecex）活跃**：TEC 调整与反倾销动议常态化审议，中国 API/中间体入巴需跟踪 Gecex 决议对 HS 税号（如 29 章/30 章）的变动。
4. **中巴/印巴双线竞争**：印巴贸易额 7 个月 101 亿美元（+32.9%），印度 API 对巴出口的份额增长可能挤压中国供应商；叠加 ApexBrasil 与印度产业界合作协议（8/26），印巴产业绑定加深，需评估对中国 API 供应商的替代压力。
5. **注册互认版图扩大**：墨西哥 Cofepris 承认 ANVISA 评估（45 个工作日简化路径）——"巴西注册 → 拉美延伸"模式成形；巴西本土 mRNA 疫苗平台（Fiocruz I 期）推进，疫苗/生物药本地化加深。
