## 二、医药行业动态

**【2026-11-02】USFDA 公开对中国豪森（连云港）与三星生物（仁川延寿）的无标题函（Form 483）：豪森无菌制剂线 7 项缺陷、灭菌验证与洁净区气流未受验证；三星生物交叉污染与数据完整性属长期系统性缺陷，七年内反复发生，56 项 CAPA 与 74 项变更控制后仍未纠正** — **豪森（Hansoh Pharma，连云港）**：检查期为 **2026-04-16 至 04-24**，**7 项缺陷**。核心问题——**设备与洁净区灭菌充分性无法证明**、灭菌工艺**未经验证**、**洁净区与无菌灌装线的气流未受适当测试**、**批间偏差与失败未充分调查**（注射剂产线附近**反复检出革兰阴性菌，源头从未追查**）、**清洁体系不当**（操作人员跨越并倚靠设备清洁、同一抹布擦拭多台设备）、**设备校准与巡检缺失**、**检查人员无培训体系与一致性评估**。**三星生物（Samsung Biologics，仁川延寿）**：检查期为 **2025 年 5 月**，**4 项缺陷**，**483 于 2025 年 10 月下旬才公开**。核心问题——**产品切换未按既定程序执行，构成严重交叉污染风险**，且**2018-10 至 2025-05 的七年间反复违规，非一次性事件**；**数据造假为重复性问题**：**班组长指示员工篡改数据**、**质量体系经理试图追查数据完整性问题的匿名举报人**、**批号与序列号在无核验情况下被更改**。FDA 指出，此前相关检查已催生 **56 项纠正预防措施（CAPA）与 74 项变更控制**，但「**数据完整性缺陷仍在持续**」。**性质限定**：Form 483 **不是 FDA 的最终结论**，**严重性低于警告信（Warning Letter）**。**对 SINOBRIGHT 的含义**：① 豪森的问题集中在**无菌注射剂**的灭菌验证与洁净区气流——这是**冻干/无菌 API 与注射剂的前置工序**，对**培南类（亚胺培南/美罗培南）、无菌头孢**等需无菌工艺的品种具参照意义：**灭菌验证包与洁净区气流研究（烟雾试验、气流可视化）**正成为客户审计的高频深挖项，我方供应无菌级 API 时，**验证文件完备度比 COA 更受关注**；② 三星生物的**「七年反复 + 56 项 CAPA 仍未纠正」**是一个**体系失效的教科案例**，说明**CAPA 数量不等于体系有效性**——客户审计中若要求供应商提供 CAPA 闭环证据，**有效性验证（effectiveness check）**将是关键；③ **数据完整性问题涉及「追查举报人」**，性质比单纯改数据更严重，会被客户的风控直接标记为**诚信风险**，进口方在下游制剂出口欧美时将被连带审查；④ 结论性判断：这批 483 **不会直接改变巴西市场的原料供应格局**（两家企业均非巴西主要 API 来源），但其**审计重点清单**应被纳入我方对巴西客户的质量沟通材料。 — 来源：[Fierce Pharma](https://www.fiercepharma.com/pharma/hansoh-and-samsung-face-fda-write-after-inspections)【依据：USFDA Form 483（豪森 2026-04 检查；三星生物 2025-05 检查），原文见 FDA 官网 483 文件】

## 三、风险提示

1. **GLP-1 上游已实质集中于印度，巴西本地企业只做注册与商业化**：10-29 批出的 5 支笔，三个注册人全部指向 Biocon（利拉鲁肽）与 OneSource Specialty（司美格鲁肽）。**「注册人 + 印度生产商」的可复用技术包模式**将快速摊薄先入者优势，价格战会早于市场预期。若我方在该品类无原料卡位，应转向**注射笔组件、辅料与注册支持服务**等周边环节，而非正面竞逐多肽 API。
2. **南共市短缺机制有效期翻倍至 24 个月，但尚未转化为国内法**：GMC 26/26 若落地，被列入短缺清单的税号可享**两个完整采购年度的零关税**。在 MDIC/SECEX 公布转化细则与清单口径前，**不得在报盘中提前让价**，但应在客户沟通中提示该通道的存在。
3. **USFDA 对无菌工艺的审计标准正在收紧**：豪森的**灭菌验证缺失、洁净区气流未受验证**，三星生物的**七年反复交叉污染与数据完整性失效**，共同指向一个趋势——**体系证据（验证包、CAPA 有效性、数据完整性）比成品检验更被看重**。这与 11-01 期「体系合规优于成品检验」的司法逻辑同向。我方供应无菌级 API（培南、无菌头孢）时，须准备**灭菌验证、气流可视化、CAPA 有效性核查**三类文件。
4. **药房渠道增量已不在药品本身**：IQVIA 显示新增营收 58% 来自消费健康，处方药（剔除 GLP-1）仅 42%。若仍以「处方药放量」为巴西需求预测的主轴，会**系统性高估传统 API 的增速**。建议将**维生素、氨基酸、营养类与胃肠类辅料**单列跟踪。
5. **消费健康领域的采购权正向零售连锁集中**：自有品牌 SKU 增加 2,780 个而工业品牌减少 5,919 个，单 SKU 产出 +45%。这意味着**连锁自有品牌的规格与成本要求将直接传导到原料端**，原有「工业客户品牌溢价」的定价逻辑在部分品类上失效。
6. **汇率小幅回升但仍处高位**：USD/BRL 报 **5.44**（er-api 11-03 00:02 UTC 5.4375），较 11-01 期的 5.40 **回升约 0.7%**，但仍显著高于 10 月初的 5.03。**R$ 计价合同的实际美元收入仍受压**，Q4 与 2027 年框架报价的**汇率调整条款**不应撤回。
