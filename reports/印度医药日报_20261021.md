## 一、政府医药政策

**【2026-10-19】医药 PLI 促成 1,931 个产品本土化生产，191 个大宗药品首次在印生产** — 官方数据：医药 PLI 累计销售逾 ₹3.64 lakh crore；大宗药品 PLI 41 个品种获批，18 个 API 已投产，含青霉素 G、克拉维酸、地塞米松、泼尼松龙、左氧氟沙星、氧氟沙星、诺氟沙星、阿托伐他汀、替米沙坦、卡马西平、双氯芬酸钠；26 个关键 API 建成约 5.5 万吨/年产能；48 个项目获批、累计投资 ₹5,070.45 crore，已发激励 ₹87.70 crore。 — 来源：[Pharmabiz](https://www.pharmabiz.com/NewsDetails.aspx?aid=191332&sid=1)

**【2026-10-19】制药司：RPTUAS 技改补贴额度已近用尽，301 家药企获批 ₹300.48 crore** — 修订版 Schedule M／WHO-GMP 技改补贴（RPTUAS，总预算 ₹300.10 crore）已批准 301 份申请、金额约 ₹300.48 crore，接近额度上限；157 家已完成升级并取得合规证书，110 家在建，另有 4 家被撤销。该司要求行业协会督促会员及时补齐材料以加快放款。 — 来源：[Pharmabiz](https://www.pharmabiz.com/NewsDetails.aspx?aid=191336&sid=1)

## 二、医药行业动态

**【2026-10-19】印度药品出口 H1 FY27 增 4.9% 至 161.3 亿美元，医药进口 47.73 亿美元增 2.48%** — 商工部初步数据：4—9 月药品出口 161.3 亿美元（上年同期 153.8 亿），Q2 增 3.04% 至 80.35 亿、9 月增 4.7% 至 27.44 亿；医药进口 47.73 亿美元，Q2 降 4.31%、9 月微降 0.19%。FY26 出口 311.2 亿美元、仅增 2.13%，低于 FY25 的 9.39%。 — 来源：[Pharmabiz](https://www.pharmabiz.com/NewsDetails.aspx?aid=191333&sid=1)

## 三、重点客户动态

**【2026-10-20】ANUH PHARMA 启用塔拉普尔 Unit F-10 原料药新厂（更新）** — 公司公告塔拉普尔 MIDC Plot F-10/1 的 API 装置正式启用；此前披露以 ₹72.9 crore 收购 Vanquest 该厂区，年增产能约 525 吨，为其 2024 年以来第三个 API 生产区块。 — 来源：[Anuh Pharma](https://www.anuhpharma.com/)【依据：公司公告 2026-10-20】

**【2026-10-20】SUN PHARMA 拟发 ₹10,000 crore 五年期债券，置换 Organon 收购过桥贷款** — 拟通过两档五年期债券融资 ₹10,000 crore（约 10.5 亿美元，含 ₹3,000 crore 绿鞋）：首档 ₹3,000 crore、17 个月末设回售权；第二档至少 ₹5,000 crore、绿鞋 ₹2,000 crore，子弹结构；票息 8.05% 与 8.20%，周四簿记。资金用于部分置换收购 Organon 的美元过桥贷款。 — 来源：[ET Pharma](https://pharma.economictimes.indiatimes.com/news/pharma-industry/sun-pharma-to-issue-over-five-year-bonds-bankers-say/135059850)

**【2026-10-20】SUN PHARMA 的 UNLOXCYT 获 NCCN 指南 2A 类优先推荐** — 美国 NCCN 最新指南将 cosibelimab-ipdl（UNLOXCYT）列入局部晚期皮肤鳞癌（不适合根治性手术或放疗者）2A 类优先方案，为该品种美国市场准入提供支撑。 — 来源：[Sun Pharma](https://www.sunpharma.com/media/press-releases)【依据：公司公告 2026-10-20】

## 四、风险提示

- **甾体 API 本土替代** — 对 SINOBRIGHT 的影响：泼尼松龙、地塞米松已列入 PLI 在产清单，甾体出口报价与份额承压，须转向未覆盖品种。
- **客户出口动能走弱** — 对 SINOBRIGHT 的影响：印药企 Q2 出口仅增 3.04%，采购节奏放缓，压价与延长账期诉求上行。
- **卢比 94.9 一线叠加股市连跌** — 对 SINOBRIGHT 的影响：外资净卖出削弱买方支付能力，报价有效期宜缩短并前置结算币种。
