**【2026-10-15】政府扩大战略意义药品（SZLS）清单：新增 4 个品种（两种人胰岛素、仑伐替尼、替奈普酶），第 2895-r 号令** — 俄联邦政府总理米舒斯京签署**第 2895-r 号令（2026-10-13）**，在**战略意义药品清单（SZLS）第二部分**新增 4 个品种：**双相人基因工程胰岛素**、**可溶性人基因工程胰岛素**、**抗肿瘤药仑伐替尼（lenvatinib）**、**用于急性心肌梗死的溶栓药替奈普酶（tenecteplase）**。**制度背景**：SZLS 清单由**第 942-r 号令（2026-04-23）**批准，初始含 **206 个 MNN**（比 2020 年版少 9 个），**分两部分、适用不同支持措施**——**第一部分适用"第二多余"规则（vtoroy lishniy，有国产药即不允外国药进入）**，**第二部分适用价格优惠（最高 30%）**。**本部新增入第二部分**。**决策依据**：政府称"**基于药品生产商提交的建议**"；**卫生部委员会于 2026-09-25 会议同意**新增该 4 项，**同时否决 9 个 MNN 的准入申请**（含丙泊酚 propofol 与促卵泡素 α follitropin alfa）。**SZLS 制度要求全流程生产须立足于俄境，组织生产可获国家支持**；**清单内药品在政府采购中享有优先权**。米舒斯京称"**须继续扩大产量，让大城市与小居民点的公民都能获得国产药品**"。**上游含义**：**仑伐替尼与替奈普酶纳入清单将加速其原料药（API）与关键中间体的本地化替代**，**人胰岛素两款入列则强化重组胰岛素产能与配套纯化材料的国产化压力**；**对华供应商而言，该 4 品种的原研 API 出口窗口趋于收窄，但清单一旦落地，配套中间体与起始物料仍有第三方供应位**。 — 来源：[Pharmvestnik](https://pharmvestnik.ru/content/news/pravitelstvo-rf-dobavilo-v-perechen-szls-chetyre-pozicii.html) · [GxP News](https://gxpnews.net/2026/10/pravitelstvo-rasshirilo-perechen-szls-na-chetyre-naimenovaniya/)

## 四、风险提示

**1. 战略意义药品清单（SZLS）扩容对进口 API 的直接挤压** — **本期第 2895-r 号令新增 4 个品种（两种人基因工程胰岛素、仑伐替尼、替奈普酶）入第二部分**。**风险机理**：**SZLS 制度要求全流程生产立足于俄境、清单内药品在政府采购中享优先权**——**第二部分虽适用"价格优惠（最高 30%）"而非"第二多余"规则，但仍构成实质性的进口替代加速器**。**对 SINOBRIGHT 的传导**：**①仑伐替尼与替奈普酶的原研 API 在俄公开招标中的份额将随国产化推进而收窄**；**②但该 4 品种在实现全流程本地化之前，中间体、起始物料与关键试剂（如替奈普酶的重组表达用培养基与纯化填料、仑伐替尼的合成中间体）仍存在第三方供应窗口**；**③人胰岛素两款入列，将强化重组胰岛素产能与配套纯化材料的国产化压力**。**建议动作**：**跟踪 Vademecum / Pharmvestnik 对"俄罗斯性（俄罗斯性）"积分细则的后续披露，据此判断中间体供应的合规空间**。

**2. EAEU GMP 合规双轨：证书即出口通行证，亦为外来者的门槛** — **本期两条并列证据**：**①Natsimbio"FORT"厂 10-15 获 EAEU GMP 证书（3 年期）**，**官方明确表述该证书"为产品进入 EAEU 国家市场、扩大出口潜力创造机会"**；**②工贸部拟将药品生产许可与 EAEU GMP 标准并轨（第 686 号决议修订草案，见本报 10-14 期）**，**新设"严重违规"类别，许可可中止最长 120 天、可延 60 天整改、逾期 10 个工作日终止**。**风险机理**：**EAEU GMP 正从"合规要求"演变为"市场准入 + 出口资格"的双重过滤器**——**一方面抬高外来生产商的合规成本（境外 GMP 检查费拟上调至 551 万卢布，含 22% 增值税）**，**另一方面为俄企打开 EAEU 出口通道**。**对 SINOBRIGHT 的传导**：**若以中国生产基地直接供货俄方，须评估 EAEU GMP 检查的排期与费用；若经俄境内合作伙伴，则需在合同层面明确 GMP 责任分配**。**结构层提示**：**2026-12-28 为 EAEU GMP 过渡期截止日**，**ARFP 已致函工贸部请求延长**（见本报 10-03 期线索），**延期与否将影响整个 2027 年的合规排期**。

**3. 零售市场"金额 +11.5% / 实物 -3.0%"剪刀差固化：价格驱动型增长的价格风险** — **RNC Pharma 1—3 季度报告显示单盒均价 +15%、北高加索与中央区金额领跑，而所有联邦区实物动态均为负**。**风险机理**：**制剂端依赖提价维持增长，一旦提价空间被行政手段压缩（FAS 已在就 13 个热门品种施压降价，参见本报 10-15 期 Otisipharm 案），金额增长将失去支撑**。**对上游的含义**：**成本端压力向 API 采购转移的动机增强**——**这为中国低成本 API 创造了相对有利的议价位置，但同时意味着价格谈判更为激烈**。**关注点**：**RNC 测算的 9 月零售药价通胀 6.53% 低于俄统计局官方 7.97%，两者口径差异（RNC 为全品类加权、统计局为一篮子）需在分析中区分**。

**4. 高值药采购链的供应稀缺风险：依维莫司二次流标** — **FTsPiLO 的"Krug Dobra"依维莫司采购在单价由 954.80 上调至 977.32 卢布（+2.4%）后仍无任何应标**，**合同额 4,656 万卢布**；**9 月底同类采购（pegcetacoplan 与 everolimus）已因相同原因失败**。**风险机理**：**"提价仍无人应标"表明该品种的合格供应商极度稀缺或产能排期无法覆盖**，**指向 mTOR 抑制剂的原料药供给集中度过高**。**对上游的含义**：**若流标持续，FTsPiLO 可能转向单一来源采购或大幅提高价格上限，形成短期的价格与供应双重不确定性**；**中国依维莫司 API 供应商若具备 EAEU GMP 资质，存在填补该缺口的窗口期**。**建议动作**：**跟踪下轮拍卖公告与 zakupki.gov.ru 的采购方式变更（是否转为单一来源）**。

**5. 制裁与进口替代监控快照（本期增量）** — **①制裁层面**：**本期未观察到新增涉俄医药/API/化工出口限制条目**（**欧盟第 22 轮制裁 10-12 生效、第 23 轮仍处信号阶段，均见本报 10-13 / 10-15 期**）；**②进口替代层面**：**本期为近一周"进口替代密度"最高的一期**——**SZLS 清单扩容（+4 品种）、首个国产 Ocrevus 生物类似药注册、R-Pharm 头颈癌单抗获"俄罗斯制造"认证、Natsimbio 获 EAEU GMP 证书**，**四条共同指向"高值生物药与疫苗的本地化闭环正在形成"**；**③平行进口**：**本期无清单调整动态**；**④中俄医药贸易准入**：**本期无新增注册互认或认证变化**；**⑤卢布汇率快照**：**1 USD ≈ ₽83.62（2026-10-16 实时中间价）**，**较 10-15 的 83.62 持平，连续第三期稳定在 83.6 附近**——**汇率稳定对 API 长单报价构成中性偏正面条件**；**⑥涉制裁企业标记**：**本期收录条目中未命中涉制裁清单企业**。
