1. **GLP-1 上游"去单极化"会改变我方在该品类的定位**：ANVISA 于 11-03 向中国 Sinopep-Allsino（连云港）颁发覆盖司美格鲁肽/替尔泊肽原料的 CBPF，加上 10-29 期五支笔全部指向印度 Biocon、OneSource，**多肽 API 的成本竞争将比预期更早激化**。若我方不在多肽赛道，**须避免以"GLP-1 高毛利"外推整体 API 价格水平**——这是与抗生素/甾体主线完全不同的价格逻辑。
