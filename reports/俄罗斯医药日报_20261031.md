## 四、风险提示

**① 专利侵权的行政责任重构，是本期对原料药与中间体出口方最关键的制度变化。** 经济发展部草案将药品专利侵权的处罚上限由固定金额（法人 3 万—4 万卢布）改为**侵权药品营收的 50%—200%**，并配套财产与账户查封。这意味着仿制药立项阶段的专利自由实施评估不再是"诉讼成本管理"问题，而是**营收级别的风险敞口**。对以"专利到期窗口"为切入逻辑的品种，须在报价前完成目标国的专利族状态与强制许可判例核查。

**② 强制许可"程序门槛化、权利金梯度化"双向收口。** 一方面是 Roche 与 AIPM 主张的三项前置核查（真实短缺、责任归属、实际效用），另一方面是巴瑞替尼二审维持的 2.1% 实际销售额权利金、卡博特韦案 1.75% 的既有先例。**对纯 API 出口方的含义：即便下游制剂厂获得强制许可，原料供应仍须接受"权利金成本传导"——合同中应明确专利权人索赔的分担条款。**

**③ 优惠供药的可诉性已扩展至"未注册药品"。** "向日葵"基金监测显示，法院认定**药品未在俄注册不构成拒绝供药的合法理由**，且 13% 患者胜诉后仍等待逾一年。该判例方向与 10-27 期"未注册药品列为主要投诉成因"形成闭环：**未注册药品的院内/优惠渠道准入正在被司法实践实质性打开，这为"API + 制剂一次性进口/个体化制备"提供了非注册路径，但财政延迟仍是主要瓶颈**。

**④ 患者支付能力与自费品类的剪刀差扩大。** GLP-1 品类 99% 由患者自费，而零售端优惠供药纠纷集中于财政不足。两个信号同向：**纳入目录的品种面临价格谈判压力，未纳入的自费品种（司美格鲁肽、替尔泊肽）则以纯市场定价运行。对上游供应商而言，自费品类的量价弹性更大，但汇率与终端促销（如 Geropharm 9 月降价 20%）会快速压缩中间体议价空间。**

**⑤ 对俄制裁与进口替代监控（本期快照）。** 欧盟第 22 轮制裁（10-12 生效）后未见针对医药/原料药的直接新增条目；本期进口替代密度中等偏上，方向集中于**疫苗（Pfizer 脑膜炎 B 群）、原研口服药（Polisan Remaksoliv）、高费用病种生物药（VZN 招标中的凝血因子与酶制剂）**，未出现大宗 API 本地化项目。★ **涉制裁企业：Pharmasyntez**——其美国关联主体仍在制裁名单内，本期无新增负面事件。

**⑥ 卢布汇率快照。** 俄央行 2026-10-31 生效价 **1 USD = 80.5573 卢布**，人民币兑卢布 **100 CNY = 1,775.52 卢布（1 CNY ≈ 17.7552 卢布）**。较 10-30 的 80.6761 微幅走强 0.15%，**连续第四期处于 80—81 区间，短期 80 为关键心理位**。汇率稳定有利于以美元计价的原料药合同重新议价，但须注意 11 月公用事业费率上调对通胀的推升效应。
