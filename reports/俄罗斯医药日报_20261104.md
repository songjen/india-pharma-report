## 四、风险提示

**① 俄方首度以"医药工业用"为由对上游石化品实施出口禁令，中方以俄为原料来源的采购结构须重估。** 第 **1443** 号决议对**苯、甲苯、邻/对二甲苯、苯酚**实施**三个月**出口禁令（EAEU 以外），官方明示**该批产品用于医药工业**。**含义**：这不是针对医药的专项管制，而是**"原料优先内保"逻辑首次明确覆盖医药上游**。**受影响链条**：**苯酚→对乙酰氨基酚/阿司匹林/水杨酸系**；**甲苯→苯甲酸、对甲苯磺酸、维生素与杂环中间体**；**对二甲苯→PTA→药用 PET 包装**。**建议**：(a) **即刻盘点**以俄为来源的上述原料**在库天数与在途量**；(b) 对 **2027 年 Q1 到货**的合同加入**出口管制/不可抗力双向条款**与**替代来源（中国自产或第三国）**预案；(c) **不宜按"长期禁运"定价**，禁令仅三个月，但**须把"延期或扩围"作为情景纳入**。

**② "减品规 + 增金额 + 减实物"三者并存，说明俄制药业在做"减法"，中方大宗 API 的订单将向头部品种集中。** 1—9 月 SKU **-168（-1.1%，六年首降）**、国产 **-65（十年首降）**；同期产值 **+17.8%**、零售盒数 **-3.5%**。**含义**：**俄企正主动收缩长尾品种**，把资源投向**独家与高毛利**。对中方 API 供应商的直接影响是：**询价基数下降、单品种批量上升、长尾品种订单消失**。**建议**：把客户分级从"客户维度"改为**"客户 × 品种"二维**，对**长尾品种**不再投入注册与备货资源，把资源集中于**客户明确列为战略的品种**（如 Geropharm 的替尔泊肽、Pharmasyntez 的肿瘤创新药与减重药、Renewal 的注射剂线）。

**③ 保密定价可能被终止，"原研高价窗口"正在被政策端主动关闭。** Geropharm 在部长级场合提出**国产类似药上市后终止保密定价**，卫生部副部长称"**相当合理**、愿研究"，仅待 **ФАС** 评估。**含义**：若落地，**俄本土类似药上市后原研与进口品价格将被拉回竞争性采购**，**价格锚整体下移**，进而**压低上游 API 的采购预算上限**。**建议**：在 **2027 年报价模型**中设置**"保密定价终止"情景**（价格锚下降 **10%—20%**，**属推断、待政策文本验证**），并优先承接**不依赖保密定价的品种**（ЖНВЛП 内已充分竞价的普药）。
