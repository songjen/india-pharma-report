## 三、风险提示

- **仿制药增速 3.4% 已低于调价上限（BTG Pactual 10-21 口径）**：若扣除年度药品调价，9 月仿制药实际销量可能已转负。对 API 出口的直接影响是**四季度订单从「量增」转向「价守」**，需重新校准对中国供应商的采购节奏预期，不宜沿用 2026 年上半年的 +10.4% 累计增速做外推。
- **线上药品占比翻倍至 15% 叠加平台入场（Mercado Livre / iFood）**：价格透明度上升将压缩仿制药终端价差，进而倒逼巴西厂商在 API 采购端压价；同时 ANVISA 对平台处方药销售的监管落地节奏（11 月公众咨询）决定这一压力的释放速度。
- **Eurofarma 停产唑吡坦 + Libbs 亚叶酸钙颗粒物**：两者共同指向**低毛利品种的产能退出与热带冷链的质量边界**。前者是供应端收缩，后者是质量端风险——出口亚叶酸钙、叶酸类及需冷藏注射剂时，稳定性数据须覆盖高温高湿与温度循环。
- **伪造高值耗材持续高发（Accu-Chek / NAC / Dysport / Keytruda 四案连续）**：巴西市场对「政府招标包装外流」高度敏感，合同条款中应加入批号—有效期—条码一致性核验与追溯要求。
