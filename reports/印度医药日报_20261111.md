## 一、政府医药政策

**【2026-11-09】克拉维酸涉华反倾销案 PUC/PCN 评论期二次延至 11-21，DGTR 明示此后不再延期（更新）** — 印度贸易救济总局就克拉维酸（克拉维酸钾及其胺盐，涉中国与欧盟）反倾销案的"可受调查产品范围与产品控制编码方法学"发布第二次延期：评论期由 10-30 再延至 **11-21**，并明确调查时限刚性、**此后不再延期**；须经 SETU 门户提交。该案 9-30 立案，案号 **AD/OI/054/2026**，涉 β-内酰胺类关键中间体。 — 来源：[DGTR 案件页](https://www.dgtr.gov.in/en/anti-dumping-cases/initiation-anti-dumping-investigation-concerning-imports-clavulanic-acid-also)【依据：DGTR 通知 F.No. 6/51/2026-DGTR，2026-11-09】

## 二、医药行业动态

**【2026-11-10】圣诺生物因 FDA 66-40 进口禁令向美客户退款 2,496 万美元，肽类 API 转向印度等市场** — 成都圣诺生物公告，因子公司圣诺制药 9-19 被列入 FDA 第 66-40 号进口禁令，与美客户 A 签订退货退款协议：退回 2025 年两笔订单项下部分多肽原料药，分三期退还 **2,495.96 万美元**，预计减少本年度主营收入 **1.63 亿元**、归母净利 **8,425 万元**；公司称将加快欧洲、印度、俄罗斯、韩国、东南亚等市场注册，对冲美国业务停滞。 — 来源：[新京报](https://www.163.com/dy/article/LBCUCR4C0512D3VJ.html)【依据：公司公告 2026-11-09】

**【2026-11-09】MOREPEN 以地氯雷他定切入美国处方仿制药，API 优势向制剂端延伸** — 公司新闻稿称首个美国处方仿制药地氯雷他定片 USP 5 mg 经全资美国子公司上市，规格 100 片与 500 片；其地氯雷他定 API 已供美多年；同期就西格列汀磷酸盐片 25/50/100 mg 提交首个 ANDA，仍在审评。公司称将继续以 API 与 CDMO 能力向制剂开发与美国分销延伸，并评估高活性 API 与肿瘤方向。 — 来源：[Morepen 新闻稿](https://morepen.s3.ap-south-1.amazonaws.com/investor/uploads/1794198953502-SEinPressrelease91126.pdf)【依据：公司公告 2026-11-09（NSE/BSE 备案）】

**【2026-11-10】Vector 白皮书：印度药厂"合规螺旋"，80% 未关闭调查直接延迟批放行** — 对多家已获 FDA 批准的印度制剂厂调研显示：全部受访厂均有待关闭事件积压，部分调查长达 **6 个月**；近 **80%** 受访者称未关闭调查直接延迟批放行；高管最多 **27%** 时间用于处置积压；人为差错占已报事件 **56%**，操作工每班在批生产记录平均录入 **120 条**，**80%** 主管每班监管 5 条以上产线。干预后预计可减 30–50% 新增事件、缩短 20–40% 关闭周期。 — 来源：[Indian Pharma Post](https://www.indianpharmapost.com/news/indias-130-billion-pharma-dream-faces-a-hidden-bottleneck-study-22358)

**【2026-11-10】BDR PHARMA 收购 Acme 口服固体制剂业务，强化激素与甲状腺 CDMO 产能** — BDR 从 PAG 牵头股东手中收购 Acme Formulation 口服固体制剂业务控股权，金额未披露；Acme 2005 年成立，承接甲状腺、女性性激素与复杂口服固体制剂代工，出口 40 余国，PAG 2021 年以 **₹1,054 crore（约 1.12 亿美元）**取得控股权。PAG 与创始人保留无菌注射剂平台 Immacule（Nalagarh 两厂，年产能逾 2 亿支）。 — 来源：[ET Pharma](https://pharma.economictimes.indiatimes.com/news/mergers-and-acquisitions/bdr-pharma-buys-acmes-oral-solid-formulations-biz/135696891)

## 四、风险提示

- **克拉维酸案口径 11-21 锁定** — 对 SINOBRIGHT 的影响：PUC/PCN 一旦定稿，胺盐与复配规格若未分列，克拉维酸及 β-内酰胺配套中间体的原产地举证与税号归类成本上升。
- **中国肽类 API 回流亚洲** — 对 SINOBRIGHT 的影响：被美禁令企业转攻印度，肽类与保护氨基酸报价竞争加剧，本司同类品种价格与账期承压。
- **客户合规门槛上行** — 对 SINOBRIGHT 的影响：批放行受调查积压牵制，客户倾向压缩合格供应商数量，资料不全者先出局，交期承诺须留缓冲。
- **卢比走强至 93.93** — 对 SINOBRIGHT 的影响：买方进口本币成本小幅回落，短期压价理由减弱，但锁汇与报价有效期条款更受关注。
