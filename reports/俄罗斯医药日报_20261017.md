## 四、风险提示

**1. 同一生产平台集中暂停注册证书（本期最重监管风险）** — "阿尔马维尔生物厂"（FKP Armavirskaya Biofabrika，克拉斯诺达尔边疆区）累计已有 **16 个品种**的 RU 被暂停（10-13 期 14 个 + 本期 2 个），涉 7 家持证方（Binergia、Avexima、FK Arzu-SLS、Diamed-farma、Inkamfarma、NPK Gepatoprotektsiya、Trivium XXI）。暂停原因为**生产工艺与检验方法与注册档案不符且逾期未整改**，属 GMP/注册合规类，非质量不合格。本期同时恢复 2 个阿替卡因复方品种 RU，说明**整改后可逆**。**对 SINOBRIGHT 的含义**：该厂为合同生产平台，其停产直接冲击持证方的成品供应；对上游 API/中间体供应商而言，短期内可能出现**替代生产平台的原料需求转移窗口**（布比卡因、依诺肝素、阿替卡因类）。但须注意行业协会"Lekmedobrashchenie"正筹备诉讼并向总检察院申诉，**行政决定存在被推翻的不确定性**，不宜据此作长期产能布局判断。

**2. 医药国际合作与"本地化度"绑定加深——工贸部与卫生部标准分歧构成政策不确定性** — "制药 2030"战略中期评估暴露部际分歧：卫生部主张按**临床获益**判定加速注册，工贸部主张按**俄境内本地化程度**判定并优先全流程国产。若工贸部口径占上风，**进口制剂与仅完成包装/分装的"伪本地化"品种将系统性被排除在加速通道与临床推荐之外**。叠加已披露的时间表（2027-03 前完成按适应证纳入 ZhNVLP 机制、2027-12 前建成原料与生产设备需求信息系统），**对华 API 出口商的意义在于：单纯 API 出口的价值可能被"本地化度"考核稀释，需评估以技术转移/本地化生产协议绑定客户的路径。**

**3. EAEU 注册制度进入"国家RU 消亡"的法律冲突期——短缺委员会变更程序无落点** — 工贸部司长加尔金明确指出：**国家注册证书与国家变更已不存在，仅存欧亚注册证书**，而"短缺委员会决定需作的变更竟无从落笔"，须与卫生部、欧亚经济委员会共同解决；同时拟延长条件注册证书有效期（现 1 年确认期不足）。**这是继第 686 号决议 GMP 并轨草案、2026-12-28 过渡期截止日之后的又一项制度性未决事项**。对以 EAEU 证书作为出口通行证的境外企业，**任何"证书类型/变更程序"的规则重写均直接影响在俄已注册品种的维持成本**，建议在 2026Q4 内完成在俄品种的证书类型盘点。

**4. 印度/中国/土耳其物流通道结构性收紧（本期对供应链最具操作性）** — 专家实测数据：自新罗西斯克货流转向圣彼得堡后，**等泊 5–8 周，11 月中下旬前舱位已难预订**；土耳其过境 22–24 天但班期不稳；**电子运单强制实施一个半月后仅约 15% 流程完成**。**对 SINOBRIGHT 的直接含义**：中国—俄罗斯医药/API 干线运输的**订舱提前期须显著前移（建议 8–10 周）**，并按"不同港口/不同船公司"而非"不同货代"做真实多元化；同时须计入完税价格计税基础扩大、商品归类方法变更、增值税提早缴纳与回收利用费上调带来的**到岸成本上升**。**建议将"订舱提前期"与"到岸成本上浮系数"写入对俄报价模型。**

**5. 制裁与进口替代快照** — 本期未发现新增对俄药品/API/化工出口限制条目；欧盟第 23 轮制裁仍处信号阶段，第 1231 号决议（孤儿药与高技术药品凭外国包装进口一年）首批适用品种待观察。进口替代侧本周密度较上周明显回落，主要为**存量清单扩容与注册完成**（SZLS 四品种 10-15、国产 Ocrevus 生物类似药 10-15、FORT 厂 EAEU GMP 10-15），本期新增方向为**放射性药品本地化**（哈巴罗夫斯克氟-18 无期限证书）与**古巴来源单抗在俄注册（尼莫妥珠单抗，古巴原料药 + 俄方包装分装）**——后者值得特别关注：**其"境外原料药 + 俄境内分装"的模式，是当前俄方在无法获得西方原研背景下开辟的第三条供应路径（继中国、印度之后引入古巴），可作为 SINOBRIGHT 评估"原料药 + 本地分装"合作模式的近期先例。** 未命中制裁清单企业。

**6. 卢布汇率快照** — 2026-10-17 俄央行生效价 **83.6177**（前收 83.7600），较 10-16 实时口径 83.62 **基本持平，连续第四期稳定于 83.6 附近**。日内参考区间 83.46–83.62。**判断：卢布在 83.6 一线形成短期均衡，对以美元计价的 API 出口报价影响中性；但零售端"金额增长、实物下滑"的剪刀差（1—3 季度金额 +11.5% / 实物 -3.0%，已于 10-16 期收录）意味着提价能力主要来自通胀而非真实需求扩张，汇率稳定期正是重新校准长期供货价格的窗口。**
