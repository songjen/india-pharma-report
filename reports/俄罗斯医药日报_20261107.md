## 四、风险提示

**① 彭博"进口占比 56%"与 ChemRar"俄企无力比拼原料药规模"互为印证：俄方"国产化"加深 → API 外购刚性上升，但须区分"制剂进口"与"API 进口"两个口径。** 本期测算：**2026 年 1—8 月**俄药品支出**近 7,000 亿卢布（约 86 亿美元）**，**进口占 56%**（2022 年为 57%）；同期**药品产值较 2021 年同期 +71%**。**关键判读**：**"国产占比"提升与"进口金额占比"停滞并不矛盾**——**外资在俄本地化生产（AstraZeneca、Novartis、Sanofi 在俄均有产能）产出的制剂被计为"俄产"**，而**其 API 仍从境外采购**。**含义**：**(a)** 中方 API 的需求**随俄方制剂本地化而增长**，**不随"国产化率"上升而下降**；**(b)** 但**中方在"高端原研药"上仍是补充角色**——欧盟对俄药品出口 **2026 年 1—7 月**仍**增长近三分之一至 67 亿欧元**，原研未退出；**(c)** 因此**"替代进口"的机会集中在"专利到期的通用品种"**，**不在"创新药"**。**建议**：**(i)** 以 **RNC/Cursor 的俄产仿制药清单**为准，逐项匹配 SINOBRIGHT 现有 API 与中间体，**优先锁定"制剂已本地化、API 外购"的品种**；**(ii)** 对**原研在俄仍有产能的品种**（AstraZeneca、Novartis、Sanofi 本地化线），**不作替代预期**；**(iii)** 报价中**区分"进入本地化供应链"与"进入进口制剂供应链"两种风险溢价**。

**② 医保与公共采购支付链的风险正在从"商业分销"扩散至"地方财政"，回款风险的定价需上调一档。** 本期两案并读：**"Башфармация"为 2.038 亿卢布超限处方服务费提起三审上诉**（法院认定**卫生部明知限额用尽仍继续下达发药指令**）；对照 11-06 期**"Фармгид"被判赔 2.474 亿卢布**。叠加 **SberIndex** 数据（药品支出 **+22%** 而**人均购买次数 -3.1%**——**增长源于单价而非用量**）。**含义**：**(a)** 地区预算与处方量之间存在**结构性缺口**，**"合同有效"不等于"有资金"**；**(b)** **公共采购方的信用**在评级中**不应默认优于商业分销商**。**建议**：**(i)** 对**地区国药公司、地区卫生部**类买方，**预付款比例不低于 50%**，**不接受纯赊销**；**(ii)** 在合同中**明确"限额用尽后的处置机制"**（暂停发货或重新议价），**避免复制"Башфармация"式的先履约后诉讼**；**(iii)** 回款风险溢价由 11-06 期建议的 **2%—4%** **上调至 3%—5%**（**经验值，需按买方信用评级与地区财政状况分档**）。
