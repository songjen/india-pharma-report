## 四、风险提示

**① 俄方"价格机制失灵"的先期征兆已出现：人免疫球蛋白两个标段"零投标"（本期新增，高优先级）。** 本期 ФЦПиЛО 的 5 个标段中，**两个人免疫球蛋白标段（合计 1.073 亿卢布／约 131 万美元）无任何参与申请**，其余**三项均因无竞争者而按最高合同价成交**。合读 11-20／11-23／11-24 三期已记录的**预算硬约束（2027 年卫生支出仅 +3.9%、11 项修正案被否）** 与 **Promomed 营收 +113% 的"以价换量"**，可以得出：**俄方公立采购的"最高合同价"对成本刚性的品种已不足以覆盖供应意愿**。**对中方 API 的传导**：**(a)** 血液制品、疫苗、生物药等**原料受限于生物源**的品类将出现**结构性供应缺口**，**俄方可能被迫上调这些品类的采购价或进口**；**(b)** **小分子 API 的采购价压降空间已接近极限**，**继续让价的边际收益递减**；**(c)** **建议**：**对俄报价以"成本挂钩＋年度调价"替代"固定价长协"**，**并明确"原料成本上涨触发重议"条款**。

**② "ПРОМОМЕД 模式"确立了俄方 GLP-1 类品种的供应当地化路径，多肽原料对俄出口窗口加速关闭（本期升级为中高优先级）。** 该客户 **1—9 月营收 406 亿卢布（+113%）**，**内分泌板块 +260% 至 286 亿卢布**，**替尔泊肽为俄药店全年最畅销药品**；同时其在 **11-23 期注册利那洛肽（14 肽）全流程自产**、**11-24 期利伐沙班司法胜诉**。三条事实合读：**俄方已形成"多肽自产＋司法降本＋商业渠道放量"的完整闭环**。**对中方的分层含义**：**(a)** **替尔泊肽（39 肽）与司美格鲁肽的关键原料（保护氨基酸、树脂、缩合剂）对俄需求将快速让位于本地合成**；**(b)** **但保护氨基酸与固相合成树脂的全球供应商集中度极高，俄方自产仍须依赖中方中间体**——**机会从"出口原料药"转向"出口合成砌块"**；**(c)** **建议立即核查该客户及其子公司的保护氨基酸与树脂采购渠道**，**判断中方在其供应链中的实际位置**。
