**① 俄制剂产值 +17.8% 是"金额驱动"，实物端仍在收缩，"量价剪刀差"决定物料采购节奏。** 1—9 月成品药产值 **839.2 十亿卢布（约 104.2 亿美元）、+17.8%**；同期零售端 **9 月盒数 -3.5%**、金额 **+11.5%**（前 8 个月趋势一致）。**含义**：俄方产能扩张主要集中在**高值品种（GLP-1、SGLT-2、抗肿瘤）**，而非**大宗普药**。对中方 API 供应商的含义是**订单结构分层**——**大宗品种（二甲双胍、头孢曲松侧链）以价格竞争为主、增量有限**；**高值品种的上游（多肽保护氨基酸、格列净类中间体）增量明确但门槛高**。建议报价模型**按品种分层设定毛利目标**，避免用大宗品种的低价逻辑覆盖高值品种。

**② GLP-1 品类"自费驱动 + 本土品牌垄断"的结构，正在关闭中国成品与部分 API 的窗口。** 9 月前三品牌**全部为俄本土企业产品**（Tirzetta／Promomed、Sedzharo／Geropharm、Semavik／Geropharm），三个品牌单月合计 **99.6 亿卢布（约 1.24 亿美元）**；叠加**替尔泊肽 99%、司美格鲁肽 89% 自费比例**。**判读**：俄 GLP-1 市场**既无预算壁垒、也已完成本地品牌占位**，中国成品进入的可能性极低；**API 与中间体**仍是现实路径，但须注意 **(a) 礼来／诺和诺德在俄专利状态**（替尔泊肽原研未在俄注册、专利 2024-11 终止），**(b) 俄方对"专利实施合规性"的行政监管正在收紧**（参见 10-30 期"专利侵权按营收 50%—200% 罚款"草案）。**建议**：在供货协议中加入**专利状态与自由实施（FTO）的卖方陈述保证条款**，将行政罚款风险前置分配。
