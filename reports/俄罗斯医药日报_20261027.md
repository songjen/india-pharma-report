**1. 供应商补贴合规风险从"合同条款"升级为"司法判例"，本地化合作须前置设计可验证指标** — 活性组分公司案确立三条边界：①**"产量达标≠补贴合规"**——国产份额提升、销售倍数等效益指标与实物指标具同等法律效力；②**"项目期外完成不得计入成果"**——超出协议期限的量化指标不被采信；③**疫情不构成概括免责**——须证明对"具体义务"的影响期间与程度。对中方企业参与俄工贸部补贴项目、或与俄企合建原料药产能（含技术转移协议挂钩补贴的情形），建议在协议中设置：**（a）效益指标的量化口径与核验时点；（b）不可抗力的期间认定机制；（c）指标未达成的分级罚则与延期条款**。本案罚金仅占补贴额约 9.4%，但先例可复用于更大金额项目。

**2. "注册合规"与"专利合规"在俄司法中已被明确切分，抢仿路径的司法保护期前置** — 鲁索替尼案的核心法理是：**注册证与最高出厂价本身不构成侵权威胁，但"要约销售"与"政府采购签约"即构成侵权**；同时卫生部主张"注册档案不实不构成自动撤销事由"，法院据此驳回撤证请求。后果是：**仿制药可持证但不得流通**（至 2028-06-12），且**法院拒绝颁发"未来注册的概括禁令"**（认定过于抽象）。对中方供应商的实务含义：向俄企供应"已注册但涉诉"品种的中间体，**合同须明确侵权风险的分配与召回/销毁责任**；同时注意阿克塞尔制药已于 10-12 反诉要求**强制许可**（未受理），若该请求获支持，格局将再次反转。

**3. 进口制剂"单一来源＋零本地化"组合是全俄供应最脆弱环节，秋水仙碱短缺暴露了渠道口径分裂** — 秋水仙碱案例的三重脆弱性：**原料药单一来源（意大利 Indena）、制剂单一来源（德国 Haupt Pharma）、俄境内零本地化生产**；而监管端（余量 2.4 万盒、热线零投诉）与渠道端（10 月仅售 200 盒）口径分裂，指向**分销层失衡**而非总量短缺。这是本期与 10-26 期阿塔拉克斯（羟嗪）同构的第二例。对中方 API 方的机会窗口明确：**具备高毒性生物碱合成与 GMP 能力的企业**可评估"原料出口＋俄境内灌装"或"制剂技术转移"路径；但须注意秋水仙碱的**剧毒属性带来 EHS 与储运门槛**，且俄方对"强效/有毒物质"的刑事治理正在收紧（见第 5 条）。

**4. 痴呆症领域"97% 患者未入系统"是需求侧最大缺口，但短期增量受专科人力约束** — 数据对照极具指向性：**确诊 5.2 万 vs 估算 200 万**、**特异性治疗覆盖率约 10%**、**老年医学专科医师配置 46%→2026 年底或降至 32%**、**单例照护成本每月 24 万卢布（≈2,982 美元）且以长期照护为主而非药品**。判断：**中期（2027—2028）增量将集中在"基层筛查＋口服小分子"**（多奈哌齐、美金刚、利斯的明、加兰他敏），高值抗体类（仑卡奈单抗等）在俄短期无支付基础；同时**"记忆门诊"在巴什科尔托斯坦、鞑靼斯坦、图拉、梁赞州的复制速度**是观察指标。对中方 API 方，上述四个品种的**中间体（如多奈哌齐的苄基哌啶片段、美金刚的甲基金刚烷骨架）**是明确窗口。

**5. 制裁与进口替代监控（本期无新增制裁条目；进口替代呈"补贴违约判例＋研发能力集中化"两条线）** — **制裁侧**：本期未监测到欧盟、美国新增涉俄药品/API/化工品出口限制条目；既有口径仍为——第 22 轮制裁（10-12 生效，约 1,600 项清单，聚焦弹道导弹与军民两用）与欧盟 10-08 延长对俄个人/实体制裁至 2027-10-09，**医药明确排除在人道主义禁运之外**。**本期新增的制裁相关司法信号**：俄最高法院受理俄纳米公司再审制药合成公司出售爱沙尼亚科韦尔特公司案——**"以制裁为不可抗力低价出表"的合法性存疑**，涉制裁资产交易的不确定性上升。**进口替代侧**：两条线并行——①**补贴违约判例化**（活性组分公司846 万卢布，效益指标与实物指标同权）；②**能力集中化**（马布斯凯尔研发中心整合、25 个生物类似药、2027 年投产）。**中俄医药贸易准入**：本期无新规；中国商务部、科技部 2026 年第 48 号公告（10-16）拟新增生物医药 5 项技术出口管制，**明确"对外授权许可、利用相关技术工艺提供外包研发与生产服务"不纳入管理范围**，CRO/CDMO 与许可交易不受影响。**卢布汇率**：实时 **80.49**、俄央行 10-27 生效价 **80.4909**（人民币/卢布 12.0680），**连续第五期走强**；对以美元计价的 API 出口方，**结算币种与账期管理**仍优先于价格谈判。**★ 涉制裁企业**：本期命中 **制药合成公司（公开股份公司，圣彼得堡）**——其爱沙尼亚子公司科韦尔特公司自 2014 年起受爱沙尼亚与欧盟制裁、2022 年起业务被阻断，且公司自身处于财务困境（2025 年净亏 2.53 亿卢布）、2026 年 6 月曾被申请破产（9 月终止）；与该公司或其子公司交易须做制裁与破产双重筛查。
